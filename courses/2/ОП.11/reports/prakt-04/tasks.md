# Практика 4. Службы, маршруты и удалённый доступ

## Часть 1. Служба

```bash
python3 -m http.server 8080
curl -I http://localhost:8080/
```

| Проверка | Команда | Ожидание |
|---|---|---|
| локально на ВМ | `curl -I http://localhost:8080/` | 200 OK |
| с хоста через проброс | `curl -I http://127.0.0.1:8080/` | 200 OK |

## Проброс портов

| Имя | Протокол | Порт хоста | Порт гостя |
|---|---|---:|---:|
| web | TCP | 8080 | 8080 |
| ssh | TCP | 2222 | 22 |

## Часть 2. SSH и туннель

```bash
ssh -p 2222 user@127.0.0.1
ssh -L 9090:localhost:8080 -p 2222 user@127.0.0.1
```

| Проверка | Команда | Ожидание |
|---|---|---|
| SSH | `ssh -p 2222 user@127.0.0.1` | вход выполнен |
| туннель | `curl -I http://127.0.0.1:9090/` | 200 OK |
