## Что требуется

Создать две виртуальные машины и соединить их сетью. Проверить связь в изолированной сети, затем изменить режим адаптера и объяснить результат.

Работа состоит из четырёх частей:

1. подготовка двух машин;
2. внутренняя сеть и статические адреса;
3. проверка `ping`;
4. смена режима на NAT и мост.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Проверьте машины

Убедитесь, что обе машины запускаются и входят в систему. Запишите их имена и версии ОС.

### Шаг 2. Включите внутреннюю сеть

В настройках каждой машины выберите адаптер 1:

- тип подключения: «Внутренняя сеть»;
- имя сети: `lab-net`.

Имя должно совпадать у обеих машин.

### Шаг 3. Назначьте адреса

На первой машине задайте `192.168.10.1/24`, на второй `192.168.10.2/24`. Шлюз не нужен: сети изолированы.

В Linux:

```bash
sudo ip addr add 192.168.10.1/24 dev enp0s3
sudo ip link set enp0s3 up
```

В Windows адрес задаётся в свойствах адаптера.

### Шаг 4. Проверьте связь

С первой машины:

```bash
ping -c 3 192.168.10.2
```

Со второй:

```bash
ping -c 3 192.168.10.1
```

Оба теста должны пройти. Если нет, проверьте имя внутренней сети и маску.

### Шаг 5. Смените режим

По очереди переключите адаптер первой машины на NAT и на мост. После каждого переключения записывайте:

- какой адрес выдаётся;
- видит ли машина интернет;
- видит ли её вторая машина.

Во внутренней сети вторая машина видна, в NAT нет, в режиме моста может быть видна в зависимости от физической сети.

### Шаг 6. Соберите схему

Нарисуйте схему из двух машин, виртуального коммутатора и режима подключения. Подпишите адреса и порты.

### Шаг 7. Соберите отчёт

Заполните разделы: цель, схема, таблица адресов, вывод `ping`, сравнение режимов, вывод.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Машины не соединены или адреса не назначены |
| 3 | Связь есть, но режимы не сравнены или схема неполная |
| 4 | Все части выполнены, отчёт заполнен, есть мелкие недочёты |
