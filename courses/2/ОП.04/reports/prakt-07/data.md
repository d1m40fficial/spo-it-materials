# Данные практики 7

## Текст

```text
Алгоритм данные алгоритм результат данные алгоритм программа результат данные алгоритм ошибка программа тест
```

## Ориентиры для проверки

| Показатель | Значение |
|---|---:|
| слов всего | 13 |
| уникальных слов | 6 |

Частоты:

| Слово | Частота |
|---|---:|
| алгоритм | 4 |
| данные | 3 |
| программа | 2 |
| результат | 2 |
| ошибка | 1 |
| тест | 1 |

Топ-5: алгоритм, данные, программа, результат, ошибка. Порядок при равной частоте задаёт алфавит.

## Проверки

| Что проверить | Ожидание |
|---|---|
| регистр | слова в нижнем регистре |
| знаки препинания | в этом тексте их нет, но функция должна их учитывать |
| пустой текст | пустой словарь, программа не падает |
| одно слово | одна пара в словаре |
| топ при малом числе слов | список короче пяти |
