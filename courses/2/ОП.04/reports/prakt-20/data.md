# Данные практики 20

## Граф

```text
A: B, C
B: A, D
C: A, D, E
D: B, C, F
E: C, F
F: D, E
G: (изолирована)
H: I
I: H
```

## Ориентиры

| Показатель | Значение |
|---|---|
| порядок BFS из A | A, B, C, D, E, F |
| путь A → F | A, B, D, F |
| длина A → F | 3 |
| путь A → G | нет |
| путь H → I | H, I |
| путь A → A | A |
| компонент связности | 3 |

## Проверки

| Что проверить | Ожидание |
|---|---|
| старт равен цели | одна вершина, длина 0 |
| отсутствующая вершина | `None` |
| изолированная вершина | путь только к себе |
| пустой граф | `None` |
| несколько компонент | 3 |
| порядок соседей | влияет на порядок BFS |
