# Данные практики 8

## Старый каталог

```text
кружка, блюдце, чайник, ложка, коробка
```

## Новый каталог

```text
блюдце, чашка, ложка, тарелка, коробка
```

## Ориентиры для проверки

| Показатель | Значение |
|---|---:|
| позиций в старом каталоге | 5 |
| позиций в новом каталоге | 5 |
| общих товаров | 3 |
| только в старом | 2 |
| только в новом | 2 |
| симметричная разность | 4 |

## Проверки

| Что проверить | Ожидание |
|---|---|
| повторы в списке | множество убирает дубли |
| порядок вывода | для сравнения используют `sorted` |
| пустой каталог | пустое множество, программа не падает |
| одинаковые каталоги | разности пусты, симметричная разность пуста |
