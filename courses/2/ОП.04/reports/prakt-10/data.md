# Сценарии практики 10

Вводите значения по одному, каждое с новой строки.

## Чтение числа

| Ввод | Ожидание |
|---|---|
| `42` | 42 без ошибок |
| `abc` | сообщение и повтор |
| `12.5` | сообщение и повтор |
| `-7` | -7, отрицательное число допустимо |
| три ошибки подряд | функция возвращает `None` |

## Меню

| Ввод | Ожидание |
|---|---|
| `1` | сложение |
| `3` | деление |
| `0` | выход |
| `5` | повтор запроса |
| `два` | повтор запроса |

## Деление

| a | b | Ожидание |
|---:|---:|---|
| 10 | 2 | 5.0 |
| 7 | 2 | 3.5 |
| 10 | 0 | сообщение, запись в журнал |
| 0 | 5 | 0.0 |

## Проверки

| Что проверить | Ожидание |
|---|---|
| журнал пуст | сообщение об успешной работе |
| несколько ошибок | все записи перечислены |
| выход через `0` | программа завершается без деления |
| повторный запуск | журнал начинается заново |
