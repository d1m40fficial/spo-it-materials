## Что требуется

Написать программу `catalog_compare.py`, которая сравнивает старый и новый каталоги товаров. Нужно вывести:

1. размеры каталогов;
2. общие товары;
3. товары, которые исчезли;
4. товары, которые появились;
5. полный список изменений и проверку согласованности.

Каталоги заданы в программе. Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Постройте множества

Преобразуйте списки через `set`:

```python
base_set = set(BASE)
new_set = set(NEW)
```

Выведите размеры. Для основного задания в каждом каталоге по 5 позиций. Если размер меньше числа элементов списка, значит, в списке были повторы.

### Шаг 2. Общие товары

Пересечение находят через `&`:

```python
common = base_set & new_set
```

Ожидается 3 общих товара. Выведите их через `sorted(common)`, чтобы порядок был предсказуемым.

### Шаг 3. Что исчезло

Разность `base_set - new_set` даёт товары, которые были в старом каталоге и пропали из нового. Ожидается 2 позиции.

Не перепутайте порядок: `a - b` и `b - a` дают разные результаты.

### Шаг 4. Что появилось

Разность `new_set - base_set` даёт новые позиции. Ожидается 2 позиции.

Сравните суммы: число общих плюс число исчезших должно равняться размеру старого каталога. Это хорошая проверка.

### Шаг 5. Полный список изменений

Симметричная разность `base_set ^ new_set` содержит всё, что отличается в любую сторону. Ожидается 4 позиции.

Проверьте согласованность:

```python
consistent = (base_set ^ new_set) == ((base_set - new_set) | (new_set - base_set))
```

Результат должен быть `True`. Если получилось `False`, одна из операций записана неверно.

### Шаг 6. Оформите вывод

Соберите отчёт в консоли:

```text
Старый каталог: 5 позиций
Новый каталог: 5 позиций
Общие: ['блюдце', 'коробка', 'ложка']
Исчезли: ['кружка', 'чайник']
Появились: ['тарелка', 'чашка']
Изменился состав: ['кружка', 'тарелка', 'чайник', 'чашка']
```

Порядок в последней строке зависит от сортировки. Используйте `sorted`, чтобы он не менялся между запусками.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| повторы в списке | множество убирает дубли |
| пустой старый каталог | все позиции новые |
| одинаковые каталоги | разности пусты |
| товар есть в обоих | попадает в общие, но не в изменения |

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код.
3. Результаты пяти частей.
4. Таблица проверок.
5. Вывод: чем разность отличается от симметричной разности.

Вставьте скриншот запуска.
