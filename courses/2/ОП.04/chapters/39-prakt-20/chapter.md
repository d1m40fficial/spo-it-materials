## Что требуется

Написать программу `route.py`, которая ищет маршрут в графе. Программа:

1. хранит граф списком смежности;
2. выполняет обход в ширину;
3. находит кратчайший путь между вершинами;
4. считает число шагов;
5. обрабатывает недостижимую вершину и изолированные компоненты.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает граф и пустые маршруты. Пока в файле `TODO`, поиск не выполняется.

### Шаг 2. Проверьте список смежности

Граф задан словарём. Убедитесь, что для каждого ребра связь записана в обе стороны: если `B` есть в списке `A`, то `A` есть в списке `B`.

Для ориентированного графа это правило не выполняется, но в этой работе граф неориентированный.

### Шаг 3. Обход в ширину

Реализуйте функцию `bfs(graph, start)`, которая возвращает список вершин в порядке обхода. Используйте `deque` и множество посещённых.

Для старта `A` ожидается порядок `A, B, C, D, E, F`. Вершины `G`, `H`, `I` в обход не попадут: они в других компонентах.

### Шаг 4. Восстановление пути

Добавьте словарь `parent`. При добавлении соседа записывайте, откуда в него пришли. После обхода постройте путь от цели к старту и переверните его.

Для `A → F` при порядке соседей из задания ожидается `A, B, D, F`. Другие кратчайшие маршруты тоже допустимы, если их длина равна трём рёбрам.

### Шаг 5. Длина маршрута

Длина пути это число рёбер, то есть `len(path) - 1`. Для `A → F` ожидается 3.

Для старта и цели, совпадающих между собой, путь равен одной вершине, а длина 0.

### Шаг 6. Недостижимые вершины

Для пути `A → G` функция должна вернуть `None`: вершина `G` изолирована. Для `H → I` путь существует и состоит из двух вершин.

Посчитайте число компонент связности: обойдите все вершины и запускайте новый обход для непосещённых. Ожидается 3 компоненты.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| старт равен цели | путь из одной вершины |
| вершина отсутствует | `None` или сообщение |
| изолированная вершина | путь только к себе |
| пустой граф | `None` |
| несколько компонент | 3 компоненты |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, порядок обхода, маршруты, таблица проверок, вывод о BFS. Вставьте скриншот.

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |

| 3 | BFS работает, но путь или недостижимые вершины обработаны неверно |
