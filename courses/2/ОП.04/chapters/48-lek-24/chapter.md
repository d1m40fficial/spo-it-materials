## Файл, который не помещается в память

В журнале миллион строк. Если прочитать его целиком, список займёт сотни мегабайт, а нужны только строки с ошибками.

```python
def error_lines(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            if "ERROR" in line:
                yield line.strip()
```

Функция с `yield` не выполняется сразу. Она возвращает генератор, который выдаёт по одной строке за раз.

```python
for line in error_lines("log.csv"):
    print(line)
```

Память занята одной строкой, а не всем файлом. Генератор читает файл по мере обхода.

Главная мысль занятия: **генератор отделяет производство значений от их потребления**. Декоратор отделяет общую обёртку от полезной работы. Структура проекта отделяет ответственности по файлам.

## Генераторы

Генератор это функция, в теле которой есть `yield`. При вызове она возвращает объект-генератор.

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

gen = countdown(3)
print(next(gen))
print(next(gen))
print(next(gen))
```

```text
3
2
1
```

После третьего `next` генератор приостановлен на `yield`, но ещё не завершён. Четвёртый вызов поднимет `StopIteration`.

```python
try:
    print(next(gen))
except StopIteration:
    print("значения закончились")
```

`yield` запоминает место и локальные переменные. При следующем `next` выполнение продолжается с той же строки, а не с начала функции.

::figure generator-flow | Интерактивный генератор: нажимайте `next()` и смотрите, как значения выдаются по одному, а затем возникает `StopIteration`.

Генераторные выражения выглядят как списочные включения, но с круглыми скобками:

```python
squares = (x * x for x in range(5))
print(list(squares))
```

```text
[0, 1, 4, 9, 16]
```

Для больших потоков это экономит память. Для маленьких списков разница несущественна, и обычное включение читается проще.

## Декораторы

Декоратор это функция, которая принимает функцию и возвращает новую функцию-обёртку.

```python
import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("вызов", func.__name__)
        result = func(*args, **kwargs)
        print("результат", result)
        return result
    return wrapper

@logged
def total(price, quantity):
    return price * quantity

print(total(640, 3))
```

```text
вызов total
результат 1920
1920
```

Запись `@logged` означает `total = logged(total)`. Обёртка вызывается вместо исходной функции и может сделать что-то до и после.

`*args, **kwargs` передают любые аргументы. `functools.wraps` сохраняет имя и строку документации исходной функции, иначе в отчётах и трассировке будет `wrapper`.

Декораторы применяют для журналирования, замера времени, повторных попыток, проверки прав. Общая логика живёт в одном месте, а не копируется в каждую функцию.

## Структура проекта

Небольшой проект удобно раскладывать так:

```text
project/
  main.py
  data/
    catalog.json
  app/
    __init__.py
    readers.py
    metrics.py
    report.py
  tests/
    test_metrics.py
```

- `main.py` это точка входа, она связывает части;
- `app/` это пакет с логикой;
- `readers.py` читает данные;
- `metrics.py` считает показатели;
- `report.py` формирует вывод;
- `tests/` проверяет модули отдельно.

`__init__.py` отмечает папку как пакет. Внутри можно оставить файл пустым или экспортировать основные имена.

```python
from app.readers import load_catalog
from app.metrics import total_value
from app.report import format_report

catalog = load_catalog("data/catalog.json")
print(format_report(total_value(catalog)))
```

Такая раскладка позволяет тестировать `metrics.py` без чтения файла и менять формат отчёта, не трогая расчёты.

::figure project-structure | Точка входа импортирует модули пакета, тесты проверяют расчёт отдельно от чтения файла.

## Где структура ломается

**Исчерпанный генератор.** После полного прохода генератор пуст. Исправление: создать новый или сохранить значения в список.

**Декоратор без `functools.wraps`.** Имя функции теряется, тесты и журналы показывают `wrapper`. Исправление: добавить `@functools.wraps(func)`.

**Циклический импорт.** `readers` импортирует `report`, а `report` импортирует `readers`. Исправление: вынести общий код в отдельный модуль или перенести импорт внутрь функции.

**Запуск модуля изнутри пакета.** `python app/readers.py` ломает относительные импорты. Запускайте `python -m app.readers` или точку входа.

**Всё в одном файле.** Тысяча строк без границ трудна для тестов. Разделяйте по ответственности.

**Слишком дробные модули.** Десяток файлов по две функции тоже усложняет навигацию. Границы должны быть осмысленными.

> [!PITFALL] Генератор можно пройти только один раз. Если нужно несколько проходов, либо создавайте генератор заново, либо сохраняйте результат.

## Итоги

- `yield` превращает функцию в генератор, который выдаёт значения по одному.
- Генератор экономит память и завершается исключением `StopIteration`.
- Декоратор оборачивает функцию, не меняя её код.
- `functools.wraps` сохраняет имя и документацию обёрнутой функции.
- Структура проекта делит код на точку входа, пакет логики и тесты.
