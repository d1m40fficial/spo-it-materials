## Что требуется

Написать программу `measurements.py`, которая обрабатывает список измерений температуры. Список задан в программе, менять его вручную не нужно. Программа выполняет пять частей:

1. Считает среднее значение.
2. Строит список отклонений от среднего и находит максимальное.
3. Отбирает значения выше порога.
4. Ищет выбросы, которые отклоняются от среднего больше чем на заданную величину.
5. Берёт срез списка и считает по нему сумму и среднее.

Отдельно проверяется пустой список: среднее для него не определено, и программа должна сообщить об этом, а не делить на ноль.

Код и результаты переносятся в `report_template.docx`, отчёт сохраняется как `report.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

Откройте `starter.py` в VS Code, откройте терминал и выполните:

```bash
python starter.py
```

Заготовка печатает список, его длину и проходит по пяти частям. Пока в файле остались `TODO`, результаты остаются нулевыми. Это ожидаемо.

### Шаг 2. Среднее значение

Среднее это сумма всех элементов, делённая на их количество. Сумму считайте циклом, а не функцией `sum`, чтобы отработать накопление. Количество даёт `len`.

Для основного набора контрольное значение равно `22.48`. Если получилось другое число, проверьте, все ли десять элементов попали в сумму.

Пустой список обрабатывается отдельно:

```python
if len(temps) == 0:
    print("Измерений нет.")
else:
    mean = total / len(temps)
```

Без этой проверки программа завершится ошибкой `ZeroDivisionError`.

### Шаг 3. Отклонения от среднего

Отклонение это разница между измерением и средним. Знак показывает направление, но для поиска выброса важна величина, поэтому берут модуль через `abs`.

Соберите список отклонений циклом:

```python
for t in temps:
    deviations.append(abs(t - mean))
```

Затем найдите максимум и его индекс. Индекс нужен, чтобы указать, какое именно измерение оказалось самым далёким от среднего. Для основного набора максимальное отклонение равно `8.02`, оно относится к значению `30.5` с индексом `7`.

При печати округляйте отклонения до двух знаков: `8.020000000000003` выглядит как ошибка, хотя это обычное следствие хранения дробных чисел.

### Шаг 4. Фильтрация по порогу

Соберите новый список из значений выше порога `22.0`. Исходный список при этом не меняется.

```python
above = []
for t in temps:
    if t > 22.0:
        above.append(t)
```

Посчитайте количество и сумму отобранных значений. Для основного набора выше порога проходят четыре измерения, их сумма равна `97.90`. Проверьте, что число элементов в новом списке совпадает с числом срабатываний условия.

Отдельно проверьте порог `100.0`: новый список должен быть пустым, а сумма равной нулю. Программа при этом не должна падать.

### Шаг 5. Поиск выброса

Выброс это значение, которое отклоняется от среднего больше чем на `3.0`. Соберите список выбросов и выведите его.

```python
outliers = []
for t in temps:
    if abs(t - mean) > 3.0:
        outliers.append(t)
```

Для основного набора в списке окажется одно значение `30.5`. Остальные измерения лежат в пределах двух с небольшим градусов от среднего.

Проверьте границы: при пределе `100.0` список выбросов пуст, при пределе `0.1` почти все значения становятся выбросами. Это показывает, что порог задаёт смысл результата, а не сам алгоритм.

### Шаг 6. Срез и его статистика

Возьмите срез от индекса `2` до индекса `7` (верхняя граница не включается) и посчитайте по нему сумму и среднее.

Ожидаемый срез содержит пять значений: `22.1`, `20.9`, `23.0`, `21.2`, `19.8`. Сумма равна `107.00`, среднее `21.40`. Сравните среднее по срезу со средним по всему списку: срез без выброса даёт заметно меньшую величину.

Проверьте срез `[3:3]`: он пуст, и среднее по нему считать нельзя. Срез `[5:100]` выходит за границу, но ошибки не даёт и возвращает элементы до конца списка.

### Шаг 7. Соберите таблицу проверок

Заполните таблицу по каждой части. Кроме основного набора, добавьте хотя бы одну границу.

| Часть | Набор | Ожидалось | Получено |
|---|---|---|---|
| Среднее | основной набор | 22.48 |  |
| Среднее | пустой список | сообщение |  |
| Отклонения | `[20.0, 20.0, 20.0]` | 0.00 |  |
| Фильтр | порог 100.0 | пустой список |  |
| Выброс | предел 3.0 | `[30.5]` |  |
| Срез | `[3:3]` | пустой срез |  |

Добавьте строки для остальных проверок из `data.md`.

### Шаг 8. Соберите отчёт

Откройте `report_template.docx` и заполните разделы:

1. Тема и цель работы.
2. Код программы.
3. Результаты пяти частей.
4. Таблица проверок.
5. Вывод: почему среднее по срезу отличается от среднего по всему списку.

Вставьте скриншот терминала с запуском на основном наборе. Сохраните отчёт как `report.docx`.
