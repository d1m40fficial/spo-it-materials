## Ответ, который не прошёл проверку

Программа спрашивает подтверждение:

```python
answer = input("Продолжить? (да/нет): ")
if answer == "да":
    print("Продолжаем")
else:
    print("Отмена")
```

Пользователь вводит `Да` с заглавной буквы и получает «Отмена». Формально всё верно: строка `"Да"` не равна строке `"да"`. Но с точки зрения человека ответ один и тот же.

Вторая ловушка появляется, когда вводят лишний пробел: `"да "`. Программа снова уходит в ветвь «Отмена». Третья ловушка связана с числами: `"9" > "18"` даёт `True`, потому что строки сравниваются посимвольно, а не как числа.

Строки требуют аккуратности в трёх местах: границы, регистр и лишние символы. В этой лекции мы разберём, как устроена строка, какие операции она поддерживает и где чаще всего возникают ошибки.

## Строка это последовательность

Строка хранит последовательность символов. У каждого символа есть индекс, как у элемента списка. Нумерация начинается с нуля.

```python
word = "алгоритм"
print(word[0])
print(word[3])
print(len(word))
```

```text
а
о
8
```

Обращение к индексу за пределами строки даёт `IndexError`. Для строки из восьми символов допустимы индексы от `0` до `7` и отрицательные от `-8` до `-1`.

```python
print(word[-1])
print(word[-3])
```

```text
м
т
```

Строки в Python неизменяемы. Нельзя записать `word[0] = "А"`: интерпретатор выдаст `TypeError`. Любая «замена» создаёт новую строку.

```python
word = "алгоритм"
new_word = "А" + word[1:]
print(new_word)
```

```text
Алгоритм
```

Здесь `word[1:]` вернул копию без первого символа, а `+` приклеил новую букву. Исходная строка осталась прежней.

::figure string-slices | Индексы идут от 0, отрицательные от -1. Срез `[0:3]` берёт три символа, `[3:]` идёт до конца, `[::2]` берёт каждый второй.

Срезы работают так же, как у списков: `[start:stop:step]`, верхняя граница не включается. `word[::-1]` переворачивает строку, потому что шаг `-1` читает её с конца.

## Операции над строкой

Строки поддерживают `+` и `*`:

```python
print("Кружка" + " " + "300 мл")
print("=" * 20)
```

```text
Кружка 300 мл
====================
```

`+` склеивает строки, `*` повторяет. Число и строка без преобразования не складываются.

Сравнение строк идёт по кодам символов. Заглавные буквы имеют меньшие коды, чем строчные, поэтому `"Я" < "а"` истинно. Это редко нужно помнить, но полезно знать, почему `"Apple"` и `"apple"` не равны.

Проверка вхождения выполняется через `in`:

```python
text = "учебный текст"
print("текст" in text)
print("слово" in text)
print(text.startswith("учеб"))
print(text.endswith("текст"))
```

```text
True
False
True
True
```

`in` ищет подстроку, а не отдельное слово. Поэтому `"текст" in "контекст"` тоже истинно. Если нужно искать слово целиком, строку делят на слова.

## Методы строк

Методы не меняют исходную строку, а возвращают новую. Это важно: результат нужно сохранить или напечатать.

| Метод | Что делает | Пример | Результат |
|---|---|---|---|
| `upper()` | верхний регистр | `"да".upper()` | `"ДА"` |
| `lower()` | нижний регистр | `"ДА".lower()` | `"да"` |
| `title()` | заглавная в каждом слове | `"учебный текст".title()` | `"Учебный Текст"` |
| `strip()` | убирает пробелы по краям | `"  да  ".strip()` | `"да"` |
| `replace(a, b)` | заменяет все вхождения | `"а-б-в".replace("-", ";")` | `"а;б;в"` |
| `split(sep)` | делит на список | `"а;б;в".split(";")` | `["а", "б", "в"]` |
| `join(list)` | собирает из списка | `";".join(["а", "б"])` | `"а;б"` |
| `find(s)` | индекс первого вхождения | `"алгоритм".find("го")` | `2` |
| `count(s)` | число вхождений | `"ааба".count("а")` | `3` |

`split` без аргумента делит по любым пробелам и убирает пустые части:

```python
line = "  кружка   640   3 "
parts = line.split()
print(parts)
```

```text
['кружка', '640', '3']
```

`join` выполняет обратную операцию. Он вызывается у разделителя, а список передаётся аргументом:

```python
parts = ["кружка", "640", "3"]
print(";".join(parts))
```

```text
кружка;640;3
```

Частая ошибка: писать `parts.join(";")`. У списка такого метода нет. Разделитель стоит слева, список справа.

::figure string-lab | Живая лаборатория: меняйте строку и нажимайте кнопки, чтобы увидеть результат каждой операции.

Обратите внимание на `strip`: он убирает пробелы только по краям, внутренние пробелы остаются. Для замены внутренних пробелов нужен `replace` или `split` с последующим `join`.

## Формат и проверка

Строки часто проверяют перед преобразованием. Простой набор проверок:

```python
raw = input("Возраст: ").strip()
if not raw.isdigit():
    print("Нужно целое число")
else:
    age = int(raw)
    print(age)
```

`isdigit()` истинно, если строка состоит только из цифр. Он не пропускает минус и точку, поэтому для отрицательных и дробных чисел нужна другая проверка.

Полезные методы проверки:

| Метод | Истинно, когда |
|---|---|
| `isdigit()` | только цифры |
| `isalpha()` | только буквы |
| `isalnum()` | буквы и цифры |
| `isspace()` | только пробельные символы |
| `startswith(prefix)` | начинается с фрагмента |
| `endswith(suffix)` | заканчивается фрагментом |

Форматирование вывода выполняют `f`-строки:

```python
name = "Кружка"
price = 640
print(f"{name}: {price:.2f} руб.")
print(f"{name:>10}|")
print(f"{name:<10}|")
```

```text
Кружка: 640.00 руб.
    Кружка|
Кружка    |
```

`>10` выравнивает по правому краю в поле шириной 10, `<10` по левому. Для таблиц это удобнее, чем считать пробелы вручную.

## Сравнение без ошибок

Сравнивать ответ пользователя лучше в одном регистре и без лишних пробелов:

```python
answer = input("Продолжить? (да/нет): ").strip().lower()
if answer == "да":
    print("Продолжаем")
else:
    print("Отмена")
```

Теперь `"Да"`, `" ДА "` и `"да"` дают одинаковый результат. Цепочка методов читается слева направо: сначала `strip`, затем `lower`.

С числами в виде строк сравнение работает иначе:

```python
print("9" > "18")
print(int("9") > int("18"))
```

```text
True
True
```

Первый результат случаен с точки зрения смысла: сравниваются коды символов `"9"` и `"1"`. Второй корректен, потому что числа сравниваются как числа. Поэтому ввод, который должен стать числом, преобразуют до сравнения.

Для сортировки строк по алфавиту учитывают регистр. Если нужен порядок без учёта регистра, используют ключ:

```python
words = ["банан", "Апельсин", "вишня"]
print(sorted(words))
print(sorted(words, key=str.lower))
```

```text
['Апельсин', 'банан', 'вишня']
['Апельсин', 'банан', 'вишня']
```

В этом примере результаты совпали, но на других данных могут отличаться. Ключ `str.lower` делает сравнение независимым от регистра.

## Где строки ломаются

**Забытый `strip`.** `"да "` не равно `"да"`. Проверка: печатайте ввод в кавычках, чтобы видеть пробелы.

**Сравнение в разных регистрах.** `"Да"` и `"да"` разные строки. Исправление: `lower()` или `casefold()`.

**`split` и `join` перепутаны местами.** `list.split()` не существует, а `";".join(list)` работает. Разделитель всегда слева у `join`.

**Ожидание изменения строки.** `text.upper()` возвращает новую строку, а `text` остаётся прежней. Нужно присваивание: `text = text.upper()`.

**Индекс вместо символа.** `"abc"[1]` даёт `"b"`, а не `1`. Для получения кода символа есть `ord`, для обратного преобразования `chr`.

**Неверная кодировка при чтении файла.** Текст на русском может превратиться в набор символов, если файл открыт не в той кодировке. Об этом подробнее в лекции о файлах.

> [!PITFALL] `strip()` не удаляет пробелы внутри строки. Для `"учебный  текст"` двойной пробел останется, пока его не заменит `replace` или `split` с `join`.

## Итоги

- Строка это последовательность символов с индексами, срезами и отрицательным отсчётом.
- Строки неизменяемы: операции возвращают новую строку.
- `split` делит строку на части, `join` собирает их обратно.
- `strip` и `lower` приводят ввод к предсказуемому виду перед сравнением.
- Числа в виде строк сравниваются посимвольно, поэтому перед сравнением их преобразуют.
