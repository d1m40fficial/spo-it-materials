## Что требуется

Написать программу `shapes.py` с иерархией фигур:

1. `Shape` задаёт общий контракт.
2. `Circle`, `Rectangle`, `Triangle` наследуют его.
3. Список фигур обходится одним циклом.
4. Считаются общая площадь, самая большая фигура и сортировка по площади.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка создаёт фигуры и печатает нулевые площади. Пока в файле `TODO`, методы не реализованы.

### Шаг 2. Базовый класс

Опишите `Shape` с полем `name` и методами `area()` и `perimeter()`.

В базовом классе методы могут поднимать `NotImplementedError`: это напоминание наследнику, что контракт нужно выполнить.

```python
class Shape:
    def area(self):
        raise NotImplementedError("наследник должен реализовать area")
```

Добавьте `__str__`, который печатает название и площадь с двумя знаками.

### Шаг 3. Круг

`Circle(radius)` хранит радиус. Площадь `π * r^2`, периметр `2 * π * r`. Используйте `math.pi`.

Для радиуса `3` ожидается площадь `28.27` и периметр `18.85`.

### Шаг 4. Прямоугольник

`Rectangle(width, height)` хранит стороны. Площадь `width * height`, периметр `2 * (width + height)`.

Для сторон `4` и `5` ожидается площадь `20`, периметр `18`.

### Шаг 5. Треугольник

`Triangle(a, b, c)` хранит три стороны. Площадь считается по формуле Герона:

```python
p = (a + b + c) / 2
area = math.sqrt(p * (p - a) * (p - b) * (p - c))
```

Перед расчётом проверьте, что треугольник существует: каждая сторона меньше суммы двух других. Иначе поднимите `ValueError`.

Для сторон `3`, `4`, `5` ожидается площадь `6`, периметр `12`.

### Шаг 6. Полиморфный обход

Соберите список:

```python
shapes = [Circle(3), Rectangle(4, 5), Triangle(3, 4, 5)]
```

Одним циклом напечатайте каждую фигуру. Вызов `shape.area()` выбирает реализацию по классу. Не проверяйте тип через `isinstance` внутри цикла.

Посчитайте общую площадь. Ожидается `54.27`.

### Шаг 7. Сортировка и максимум

Отсортируйте фигуры по площади через `key=lambda shape: shape.area()`. Ожидаемый порядок: треугольник, прямоугольник, круг.

Максимум найдите циклом или через `max` с тем же ключом. Ожидается круг.

### Шаг 8. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| радиус 0 | площадь 0 |
| сторона 0 у прямоугольника | площадь 0 |
| треугольник `1, 2, 10` | `ValueError` |
| пустой список фигур | сумма 0, максимум отсутствует |
| `isinstance(circle, Shape)` | `True` |

Соберите отчёт: цель, код, результаты, таблица проверок, вывод о полиморфизме.
