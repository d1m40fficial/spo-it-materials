## Телефон, который прошёл проверку

Форма принимает номер в виде `+7-912-345-67-89`. Нужно проверить формат до отправки на сервер.

Простая проверка по длине пропускает `+7-912-345-67-8X`. Проверка по первому символу пропускает `+7-abc-def-gh-ij`. Нужен шаблон, который описывает всю строку.

```python
import re

pattern = r"^\+7-\d{3}-\d{3}-\d{2}-\d{2}$"
print(bool(re.fullmatch(pattern, "+7-912-345-67-89")))
print(bool(re.fullmatch(pattern, "+7-912-345-67-8X")))
```

```text
True
False
```

Шаблон читается как «начало, плюс и семёрка, дефис, три цифры, дефис, три цифры, дефис, две цифры, дефис, две цифры, конец».

Главная мысль занятия: **регулярное выражение описывает множество строк, а не ищет смысл**. Оно проверяет форму, но не проверяет, существует ли такой номер.

## Символы и классы

Шаблон состоит из обычных символов и специальных конструкций.

| Запись | Значит |
|---|---|
| `\d` | одна цифра |
| `\w` | буква, цифра или подчёркивание |
| `\s` | пробельный символ |
| `.` | любой символ, кроме перевода строки |
| `[abc]` | один из символов `a`, `b`, `c` |
| `[^abc]` | любой, кроме `a`, `b`, `c` |
| `[0-9]` | диапазон цифр |

Заглавные версии означают отрицание: `\D` это не цифра, `\W` не буква и не цифра, `\S` не пробел.

Специальные символы `^ $ . * + ? { } [ ] ( ) | \` имеют служебное значение. Чтобы искать сам символ, его экранируют обратной косой чертой: `\+`, `\.`, `\(`.

## Квантификаторы

Квантификатор задаёт число повторений.

| Запись | Значит |
|---|---|
| `*` | ноль или больше |
| `+` | один или больше |
| `?` | ноль или один |
| `{3}` | ровно три |
| `{2,5}` | от двух до пяти |
| `{2,}` | два или больше |

```python
print(re.fullmatch(r"\d{3}", "912"))
print(re.fullmatch(r"\d{2,4}", "12345"))
```

Первый вызов вернёт совпадение, второй нет: пять цифр не помещаются в диапазон.

Квантификатор действует на один предыдущий элемент. В `\d{3}` он относится к `\d`, в `(ab)+` к группе `ab`. Скобки нужны, когда повторять нужно несколько символов.

## Якоря и группы

Якорь `^` привязывает шаблон к началу строки, `$` к концу. Без них `re.search` найдёт телефон внутри произвольного текста.

```python
text = "Телефон: +7-912-345-67-89, звонить днём"
print(re.search(r"\+7-\d{3}-\d{3}-\d{2}-\d{2}", text))
print(re.fullmatch(r"\+7-\d{3}-\d{3}-\d{2}-\d{2}", text))
```

`search` найдёт фрагмент, `fullmatch` потребует, чтобы шаблон совпал со всей строкой.

Группы выделяют части совпадения:

```python
pattern = r"^(\d{2})\.(\d{2})\.(\d{4})$"
match = re.fullmatch(pattern, "18.11.2026")
print(match.group(0))
print(match.group(1), match.group(2), match.group(3))
```

```text
18.11.2026
18 11 2026
```

`group(0)` это всё совпадение, `group(1)` первая группа. Если шаблон не совпал, `match` равно `None`, и обращение к `group` даст `AttributeError`.

Альтернатива `|` выбирает один из вариантов: `r"^(да|нет)$"`.

## Функции модуля re

| Функция | Что делает |
|---|---|
| `re.fullmatch` | совпадение со всей строкой |
| `re.match` | совпадение с началом |
| `re.search` | поиск первого совпадения |
| `re.findall` | список всех совпадений |
| `re.sub` | замена совпадений |

```python
print(re.findall(r"\d+", "12 яблок, 7 груш"))
print(re.sub(r"\s+", " ", "  много   пробелов  "))
```

```text
['12', '7']
 много пробелов 
```

`sub` заменяет все совпадения, а не только первое. Четвёртый аргумент `count` ограничивает число замен.

Флаги меняют поведение. `re.IGNORECASE` игнорирует регистр:

```python
re.fullmatch(r"да", "ДА", re.IGNORECASE)
```

## Где шаблоны ломаются

**Нет якорей.** Шаблон находит подстроку и пропускает лишний текст. Исправление: `fullmatch` или `^...$`.

**Точка вместо класса.** `.` совпадает почти с любым символом, включая буквы. Для цифр нужен `\d`.

**Забытое экранирование.** `\.` ищет точку, `.` ищет любой символ. Для плюса нужен `\+`.

**Слишком широкий класс.** `\w+` пропускает и буквы, и цифры, и подчёркивание. Если нужен только код из заглавных букв, пишите `[A-Z]{2}`.

**Жадный квантификатор.** `.*` захватывает как можно больше. Для минимального захвата используют `.*?`.

**Проверка после `None`.** `match.group()` без проверки падает. Сначала проверьте `if match:`.

**Катастрофический откат.** Вложенные квантификаторы вида `(a+)+` на длинной строке работают очень долго. Упрощайте шаблон.

> [!PITFALL] Регулярное выражение проверяет формат, а не существование объекта. Телефон `+7-000-000-00-00` пройдёт шаблон, хотя номера может не быть.

## Итоги

- Шаблон описывает допустимые строки через литералы, классы и квантификаторы.
- `\d`, `\w`, `\s` задают классы символов, `[ ]` и `|` дают выбор.
- Якоря `^` и `$` и `fullmatch` требуют полного совпадения.
- Группы извлекают части строки, `group(1)` возвращает первую группу.
- `search`, `findall` и `sub` ищут, собирают и заменяют совпадения.
