## Что требуется

Дан список задач с началом и концом. Нужно выбрать как можно больше задач, которые не пересекаются, и посчитать загрузку.

Программа `schedule.py`:

1. печатает исходный список;
2. сортирует задачи по времени окончания;
3. выбирает совместимые;
4. считает число задач и суммарную длительность;
5. проверяет, что выбранные задачи не пересекаются.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает задачи и пустое расписание. Пока в файле `TODO`, выбор не выполняется.

### Шаг 2. Отсортируйте задачи

Ключ сортировки это время окончания:

```python
tasks = sorted(tasks, key=lambda task: task[1])
```

Сортировка по началу или длительности даёт неверный набор. Проверьте это отдельно и запишите результат в отчёт.

### Шаг 3. Выберите совместимые

Храните время окончания последней выбранной задачи. Задача подходит, если её начало не раньше этого времени.

```python
last_end = 0
selected = []
for start, end in tasks:
    if start >= last_end:
        selected.append((start, end))
        last_end = end
```

Для задач из задания ожидается 4 выбранные задачи: 9-11, 11-13, 13-15, 15-17.

### Шаг 4. Посчитайте загрузку

Суммарная длительность это сумма `end - start` по выбранным задачам. Ожидается 8 часов.

Число задач и загрузка это разные показатели: можно выбрать много коротких задач или мало длинных.

### Шаг 5. Проверьте пересечения

Для каждой пары соседних выбранных задач проверьте, что конец предыдущей не больше начала следующей.

```python
for first, second in zip(selected, selected[1:]):
    assert first[1] <= second[0]
```

Если проверка падает, ошибка в выборе или сортировке.

### Шаг 6. Сравните стратегии

Постройте расписание с сортировкой по началу и посчитайте число задач. Сравните с правильным результатом. Объясните, почему ранняя задача может блокировать несколько коротких.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустой список | 0 задач, загрузка 0 |
| одна задача | 1 задача |
| все задачи пересекаются | 1 задача |
| одинаковое окончание | выбирается первая подходящая |
| задача нулевой длины | допускается |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, выбранные задачи, загрузка, сравнение стратегий, вывод. Вставьте скриншот.

| Балл | Что оценивается |
