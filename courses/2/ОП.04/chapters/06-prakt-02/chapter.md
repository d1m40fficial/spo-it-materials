## Что требуется

Собрать программу `calculator.py`, которая принимает два числа и знак операции, выполняет выбранное действие и печатает результат. Программа не должна падать при неверном знаке или делении на ноль: вместо этого она выводит понятное сообщение.

Работа состоит из пяти частей:

1. Калькулятор с четырьмя операциями.
2. Определение знака числа и чётности.
3. Скидка по сумме покупки и статусу покупателя.
4. Оценка по баллам через лестницу условий.
5. Проверка допуска по возрасту и наличию билета.

Каждая часть проверяется отдельным набором данных. Результаты и код переносятся в `report_template.docx`, отчёт сохраняется как `report.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

Откройте `starter.py` в VS Code, откройте терминал и выполните:

```bash
python starter.py
```

Заготовка печатает заголовок и просит знак операции. Пока в файле остались `TODO`, расчёт не выполняется. Это ожидаемо: программа собирается по частям.

### Шаг 2. Выбор операции

Программа принимает два числа `a` и `b` и знак `op`. Знак хранится в строке. Сравнение строки выполняется через `==`:

```python
op = input("Операция: ")
```

Дальше нужна лестница из четырёх ветвей: `+`, `-`, `*`, `/`. Пятая ветвь `else` сообщает, что операция не поддерживается. Для деления добавьте отдельное условие: если `b == 0`, результат не вычисляется, выводится сообщение о делении на ноль.

Ожидаемые ответы для проверки:

```text
7 + 3 = 10
7 - 3 = 4
7 * 3 = 21
7 / 3 = 2.33
8 / 0: деление на ноль невозможно
7 % 3: операция не поддерживается
```

Для деления печатайте результат с двумя знаками после точки через `:.2f`. Остальные операции можно печатать как есть, если результат целый.

### Шаг 3. Знак и чётность

Программа принимает целое число и печатает два сообщения: какое это число по знаку и чётное ли оно.

- положительное, отрицательное или ноль;
- чётное или нечётное.

Для чётности используйте остаток: `number % 2 == 0`. Для знака постройте лестницу из трёх ветвей. Ноль это отдельный случай: он не положительный и не отрицательный.

Проверьте на числах `14`, `-9`, `0`. Для `14` ожидается «положительное, чётное», для `-9` «отрицательное, нечётное», для `0` «ноль, чётное».

### Шаг 4. Скидка по сумме и статусу

Магазин даёт скидку 10 процентов, если сумма покупки больше 5000 и покупатель состоит в клубе. Если сумма больше 5000, но покупатель не в клубе, скидка 5 процентов. В остальных случаях скидки нет.

Постройте условие через `and` и `else`. Скидку считайте от суммы и печатайте итог с двумя знаками.

| Сумма | В клубе | Ожидаемая скидка |
|---:|---|---:|
| 6400 | да | 10 % |
| 6400 | нет | 5 % |
| 3200 | да | 0 % |

Сумма `6400` при скидке 10 процентов даёт итог `5760.00`. Проверьте этот расчёт вручную, прежде чем запускать программу.

### Шаг 5. Оценка по баллам

Программа принимает балл от 0 до 100 и печатает оценку:

- от 90 «Отлично»;
- от 75 «Хорошо»;
- от 60 «Зачтено»;
- ниже 60 «Не зачтено».

Здесь важна не только правильная запись условий, но и порядок. Начните с самого строгого условия. Проверьте на баллах `95`, `82`, `60`, `41`.

Отдельно ответьте в отчёте: что произойдёт, если поставить проверку `score >= 60` первой? Запишите ответ до запуска, затем проверьте на практике.

### Шаг 6. Допуск по возрасту и билету

Программа принимает возраст и ответ на вопрос о билете (`да` или `нет`). Правила:

- до 18 лет проход запрещён независимо от билета;
- с 18 лет и при наличии билета проход разрешён;
- с 18 лет без билета нужен билет.

Постройте вложенное условие. Сравнение ответа о билете делайте со строкой `"да"`. Если пользователь введёт `"Да"` с заглавной буквы, условие не сработает: это повод обсудить приведение регистра через `lower()`.

### Шаг 7. Проверьте все ветви

Соберите таблицу проверок. Каждая ветвь каждого задания должна встретиться хотя бы один раз.

| Задание | Ветвь | Входные данные | Ожидаемый результат | Получено |
|---|---|---|---|---|
| Калькулятор | сложение | 7, 3, `+` | 10 |  |
| Калькулятор | деление на ноль | 8, 0, `/` | сообщение об ошибке |  |
| Калькулятор | неверный знак | 7, 3, `%` | сообщение об ошибке |  |
| Знак и чётность | ноль | 0 | ноль, чётное |  |
| Скидка | клуб, сумма больше 5000 | 6400, да | 5760.00 |  |
| Оценка | верхняя ветвь | 95 | Отлично |  |
| Допуск | нет билета | 20, нет | нужен билет |  |

Дополните таблицу своими строками, чтобы были покрыты все ветви.

### Шаг 8. Соберите отчёт

Откройте `report_template.docx` и заполните разделы:

1. Тема и цель работы.
2. Код программы.
3. Результаты пяти частей.
4. Таблица проверок по ветвям.
5. Вывод: какая ветвь оказалась самой сложной и почему.

Вставьте скриншот терминала с двумя запусками: успешным расчётом и сообщением об ошибке. Сохраните отчёт как `report.docx`.

## Что сдаётся

- `calculator.py` с программой.
- `report.docx` с кодом, результатами и таблицей проверок.
- Скриншот двух запусков: успешного и с сообщением об ошибке.

> [!PITFALL] Сообщение об ошибке это тоже результат. Если программа при делении на ноль молча завершается или печатает `inf`, ветвь не обработана, даже если остальные расчёты верны.
