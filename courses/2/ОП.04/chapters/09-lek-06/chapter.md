## Тридцать измерений и тридцать имён

На лабораторном стенде записали тридцать значений температуры. Если хранить их в отдельных переменных, получится тридцать строк:

```python
t1 = 21.4
t2 = 21.7
t3 = 22.1
```

Дальше нужна средняя температура, максимум и число значений выше порога. С отдельными именами придётся писать тридцать сравнений и тридцать сложений, а при изменении числа измерений переписывать программу.

Список решает эту задачу одним именем:

```python
temps = [21.4, 21.7, 22.1, 20.9, 23.0]
```

Теперь длину даёт `len(temps)`, сумму `sum(temps)`, а перебор записывается циклом. Список это упорядоченный набор значений, где у каждого элемента есть номер. В Python списки записывают в квадратных скобках, элементы разделяют запятыми.

Главная мысль занятия: **список хранит не одно значение, а последовательность, и работает с ней через индексы и циклы**. Почти все задачи обработки данных сводятся к обходу списка и накоплению результата.

## Индекс и длина

Индекс это номер элемента. Нумерация начинается с нуля, поэтому первый элемент имеет индекс `0`, второй `1`, последний `len(list) - 1`.

```python
temps = [21.4, 21.7, 22.1, 20.9, 23.0]
print(temps[0])
print(temps[2])
print(len(temps))
```

```text
21.4
22.1
5
```

Обращение к индексу за пределами списка даёт ошибку:

```python
print(temps[5])
```

```text
IndexError: list index out of range
```

Список из пяти элементов имеет индексы от `0` до `4`. Пятый индекс уже не существует. Эта ошибка встречается часто, когда цикл пишут как `for i in range(1, len(temps))` и теряют первый элемент или, наоборот, доходят до `len(temps)`.

Отрицательные индексы считаются с конца. `-1` это последний элемент, `-2` предпоследний.

```python
print(temps[-1])
print(temps[-2])
```

```text
23.0
20.9
```

Отрицательный индекс удобен, когда нужен последний элемент и не хочется вычислять `len(temps) - 1`. Но индекс `-6` для списка из пяти элементов тоже даст `IndexError`.

::figure list-indexing | Прямые индексы идут от 0, отрицательные от -1. Срез `[1:4]` берёт элементы с индексами 1, 2 и 3.

## Срезы

Срез это часть списка. Его записывают через двоеточие: `list[start:stop:step]`. Верхняя граница не включается, как и в `range`.

```python
temps = [21.4, 21.7, 22.1, 20.9, 23.0]
print(temps[1:3])
print(temps[:2])
print(temps[3:])
print(temps[::2])
```

```text
[21.7, 22.1]
[21.4, 21.7]
[20.9, 23.0]
[21.4, 22.1, 23.0]
```

Срез создаёт новый список. Изменение среза не меняет исходный список, если не присвоить результат обратно.

```python
part = temps[1:3]
part[0] = 0.0
print(temps)
print(part)
```

```text
[21.4, 21.7, 22.1, 20.9, 23.0]
[0.0, 22.1]
```

Границы среза могут выходить за пределы списка, и ошибки не будет. `temps[2:100]` вернёт элементы от второго до конца. Это отличается от обращения по индексу, где выход за границу запрещён.

## Обход списка

Самый простой обход перебирает значения:

```python
temps = [21.4, 21.7, 22.1, 20.9, 23.0]
total = 0
for t in temps:
    total = total + t
print(total / len(temps))
```

```text
21.82
```

Если нужен индекс, используют `enumerate`:

```python
for i, t in enumerate(temps):
    print(i, t)
```

```text
0 21.4
1 21.7
2 22.1
3 20.9
4 23.0
```

`enumerate` возвращает пару «индекс и значение» и избавляет от ручного счётчика. Это надёжнее, чем `for i in range(len(temps))`, потому что не нужно помнить про границы.

Если нужен только индекс, подойдёт `range(len(temps))`. Но в большинстве задач достаточно перебрать значения.

::figure list-explorer | Интерактивный список: нажимайте на элементы, добавляйте и удаляйте значения и смотрите, как меняются индексы и длина.

В интерактивной схеме видно, что после `append` новый элемент получает индекс, равный прежней длине. После `pop` длина уменьшается, а индексы оставшихся элементов не меняются. Это важно: индекс это позиция, а не постоянная метка элемента.

## Операции со списком

Список можно изменять. Основные операции собраны в таблице.

| Операция | Что делает | Пример |
|---|---|---|
| `append(x)` | добавляет `x` в конец | `temps.append(22.5)` |
| `insert(i, x)` | вставляет `x` на позицию `i` | `temps.insert(0, 20.0)` |
| `pop()` | удаляет и возвращает последний элемент | `last = temps.pop()` |
| `pop(i)` | удаляет и возвращает элемент `i` | `first = temps.pop(0)` |
| `remove(x)` | удаляет первое вхождение `x` | `temps.remove(21.4)` |
| `sort()` | сортирует список на месте | `temps.sort()` |
| `reverse()` | меняет порядок на обратный | `temps.reverse()` |
| `index(x)` | возвращает индекс первого вхождения | `temps.index(22.1)` |
| `count(x)` | считает число вхождений | `temps.count(22.1)` |
| `in` | проверяет наличие | `22.1 in temps` |

Методы `append`, `insert`, `pop`, `remove`, `sort` и `reverse` меняют сам список. Функции `len`, `sum`, `min`, `max` и `sorted` возвращают новое значение и список не меняют.

```python
temps = [21.4, 21.7, 22.1]
temps.append(20.9)
print(temps)
temps.sort()
print(temps)
print(sorted(temps, reverse=True))
print(temps)
```

```text
[21.4, 21.7, 22.1, 20.9]
[20.9, 21.4, 21.7, 22.1]
[22.1, 21.7, 21.4, 20.9]
[20.9, 21.4, 21.7, 22.1]
```

`sorted` вернул новый список, а `temps` остался отсортированным по возрастанию. Разница между `sort` и `sorted` важна, когда исходный порядок нужно сохранить.

## Поиск и фильтрация

Поиск значения перебирает элементы и сравнивает их с образцом.

```python
temps = [21.4, 21.7, 22.1, 20.9, 23.0]
target = 22.1
found = -1
for i, t in enumerate(temps):
    if t == target:
        found = i
        break
print(found)
```

```text
2
```

Начальное значение `-1` означает «не найдено». Такой приём часто используют вместо `None`, когда результат должен быть числом.

Фильтрация создаёт новый список из элементов, которые прошли условие.

```python
above = []
for t in temps:
    if t > 21.5:
        above.append(t)
print(above)
```

```text
[21.7, 22.1, 23.0]
```

Ту же операцию можно записать списковым включением:

```python
above = [t for t in temps if t > 21.5]
```

Списковые включения компактны, но на первых занятиях лучше сначала освоить обычный цикл с `append`, а потом переходить к короткой записи.

## Где списки ломаются

**Выход за границу.** `temps[len(temps)]` всегда даёт ошибку: последний индекс на единицу меньше длины. Исправление: `temps[len(temps) - 1]` или `temps[-1]`.

**Забытая единица в `range`.** `range(1, len(temps))` пропускает первый элемент. Исправление: `range(len(temps))` или обход значений.

**Два имени для одного списка.** `copy = temps` не создаёт копию, а даёт второе имя. Изменение через `copy` меняет и `temps`. Исправление: `copy = temps[:]` или `copy = list(temps)`.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

```text
[1, 2, 3, 4]
```

**Изменение списка во время обхода.** Если удалять элементы внутри `for`, часть элементов будет пропущена. Исправление: собрать новый список или обходить копию.

**Путаница `sort` и `sorted`.** `sort` меняет список и возвращает `None`. Запись `result = temps.sort()` запишет в `result` значение `None`.

**Сравнение списков с числом.** `temps == 21.4` всегда `False`, потому что список и число это разные типы. Нужно сравнивать элемент: `temps[0] == 21.4`.

> [!PITFALL] `remove` удаляет первое вхождение, а не все. Если значение встречается несколько раз, понадобится цикл или новый список без этого значения.

## Итоги

- Список хранит упорядоченный набор значений под одним именем.
- Индексы начинаются с нуля, отрицательные считаются с конца, длина даёт `len`.
- Срез `[start:stop]` не включает верхнюю границу и создаёт новый список.
- `append`, `insert`, `pop`, `remove`, `sort` меняют список; `sorted` возвращает новый.
- Список обходят значениями или через `enumerate`, а фильтруют новым списком.
