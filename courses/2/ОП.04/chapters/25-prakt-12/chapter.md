## Что требуется

Написать программу `tree_walk.py`, которая обходит вложенный каталог. Структура задана словарями: у папки есть `children`, у файла есть `size`.

Программа:

1. печатает дерево с отступами;
2. считает число файлов;
3. считает общий размер;
4. находит максимальную глубину;
5. строит путь к файлу по имени.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает структуру и проходит по частям. Пока в файле `TODO`, счётчики остаются нулевыми.

### Шаг 2. Печать дерева

Напишите функцию `print_tree(node, level=0)`:

1. печатает имя с отступом `level * 2`;
2. если у узла есть `children`, вызывает себя для каждого ребёнка с `level + 1`.

База это узел без детей: после печати имени функция ничего не вызывает.

Ожидаемый вид:

```text
catalog
  python
    basics
      intro.md
      types.md
    oop.md
  images
    logo.png
  readme.md
```

### Шаг 3. Число файлов

Функция `count_files(node)` возвращает:

- `1`, если узел является файлом;
- сумму по детям, если узел является папкой.

Файл определяйте по отсутствию `children` или по полю `type`. Выберите один способ и объясните его в отчёте.

Ожидается 5 файлов.

### Шаг 4. Общий размер

Функция `total_size(node)` возвращает `size` для файла и сумму размеров детей для папки.

Ожидается 188. Проверьте вручную: `12 + 18 + 30 + 120 + 8`.

### Шаг 5. Максимальная глубина

Глубину корня считайте равной `0`. Для папки глубина это `1 + максимум из глубин детей`. Для файла глубина равна `0` относительно себя.

Ожидается 3: цепочка `catalog → python → basics → intro.md`.

### Шаг 6. Путь к файлу

Функция `find_path(node, target, path)` возвращает список имён от корня до файла или `None`.

```python
find_path(TREE, "logo.png", [])
```

Ожидается `["catalog", "images", "logo.png"]`.

Если файл не найден, возвращается `None`. Проверьте на имени `missing.txt`.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустая папка | 0 файлов, размер 0 |
| файл вместо корня | 1 файл, глубина 0 |
| один уровень вложенности | глубина 1 |
| отсутствующий файл | `None` |
| повторяющиеся имена | находится первый |

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код.
3. Результаты пяти частей.
4. Таблица проверок.
5. Вывод: почему для вложенной структуры рекурсия удобнее цикла.

Вставьте скриншот запуска.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или выполнено меньше половины частей |
| 3 | Обход работает, но счётчики или путь содержат ошибки |
| 4 | Все части решены, проверки выполнены, отчёт заполнен, есть мелкие недочёты |
| 5 | Все части решены, границы проверены, база и шаг объяснены |

## Что сдаётся

- `tree_walk.py`.
- `report.docx` с кодом, результатами и проверками.
- Скриншот запуска.

> [!PITFALL] Если рекурсивная функция не уменьшает задачу, она упирается в `RecursionError`. Для дерева уменьшение это переход к детям, а не повторный вызов с тем же узлом.
