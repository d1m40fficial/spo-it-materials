## Что требуется

Написать программу `catalog_sort.py`, которая работает с каталогом товаров. Каждая запись это словарь с полями `name`, `price`, `quantity`.

Программа:

1. выводит каталог в исходном порядке;
2. сортирует по цене;
3. сортирует по названию;
4. сортирует по итоговой стоимости по убыванию;
5. ищет товар по названию бинарным поиском.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает исходный каталог и проходит по частям. Пока в файле `TODO`, сортировки не выполняются.

### Шаг 2. Сортировка по цене

Используйте `sorted` с ключом:

```python
by_price = sorted(catalog, key=lambda item: item["price"])
```

Ожидаемый порядок цен: `40, 90, 420, 640, 1250`. Проверьте, что исходный список не изменился: `sorted` возвращает новый список.

### Шаг 3. Сортировка по названию

```python
by_name = sorted(catalog, key=lambda item: item["name"])
```

Ожидаемый порядок: Блюдце, Коробка, Кружка, Ложка, Чайник. Сравнение строк идёт по кодам символов, поэтому регистр важен. Все названия начинаются с заглавной буквы, дополнительная нормализация не нужна.

### Шаг 4. Сортировка по стоимости

Стоимость вычисляется как `price * quantity`. Отсортируйте по убыванию:

```python
by_total = sorted(catalog, key=lambda item: item["price"] * item["quantity"], reverse=True)
```

Ожидаемые стоимости: 1920, 1250, 840, 540, 400.

Составной ключ нужен, когда основной критерий совпадает. Например, при равной стоимости сортируют по названию:

```python
key=lambda item: (-item["price"] * item["quantity"], item["name"])
```

Минус перед стоимостью даёт убывание без `reverse`.

### Шаг 5. Бинарный поиск

Бинарный поиск работает только по отсортированному по названию списку. Реализуйте функцию:

```python
def binary_search(records, target):
    low = 0
    high = len(records) - 1
    while low <= high:
        mid = (low + high) // 2
        if records[mid]["name"] == target:
            return mid
        if records[mid]["name"] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

Для `Ложка` ожидается индекс `3`. Для отсутствующего товара `Ваза` результат `-1`.

### Шаг 6. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустой каталог | поиск возвращает `-1` |
| один товар | поиск находит индекс `0` |
| первый товар | индекс `0` |
| последний товар | индекс `4` |
| отсутствующий товар | `-1` |
| равные цены | порядок устойчив |

### Шаг 7. Оформите вывод

Печатайте таблицу с колонками: название, цена, количество, стоимость. Для денег используйте `:.2f`. Перед таблицей укажите, по какому ключу выполнена сортировка.

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код.
3. Результаты пяти частей.
4. Таблица проверок.
5. Вывод: почему бинарный поиск требует сортировки по тому же полю.

Вставьте скриншот запуска.
