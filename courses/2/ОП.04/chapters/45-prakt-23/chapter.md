## Что требуется

Написать программу `rights.py`, которая хранит права пользователя в одном числе. Флаги:

| Флаг | Вес |
|---|---:|
| READ | 1 |
| WRITE | 2 |
| EXEC | 4 |
| DELETE | 8 |
| ADMIN | 16 |

Программа:

1. собирает начальный набор;
2. печатает двоичный вид;
3. проверяет каждый флаг;
4. включает, снимает и переключает права;
5. расшифровывает итоговое число.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Задайте флаги

Флаги это степени двойки. Запишите их через сдвиг, чтобы видеть номер бита:

```python
READ = 1 << 0
WRITE = 1 << 1
EXEC = 1 << 2
DELETE = 1 << 3
ADMIN = 1 << 4
```

Начальный набор: `READ | WRITE | EXEC`, то есть 7.

### Шаг 2. Проверьте флаг

```python
def has(value, flag):
    return (value & flag) != 0
```

Сравнение с нулём обязательно. `value & flag` возвращает число, а не `True`.

Проверьте все пять флагов у начального набора. Ожидается: чтение, запись и выполнение есть, удаления и администрирования нет.

### Шаг 3. Включите право

```python
rights |= DELETE
```

После этого число станет 15, а в двоичном виде появится бит 8.

### Шаг 4. Снимите право

```python
rights &= ~WRITE
```

Ожидается 13. Проверьте, что остальные права не изменились.

### Шаг 5. Переключите право

```python
rights ^= ADMIN
```

Если права не было, оно появится. Ожидается 29.

Повторное переключение снова его снимет. Проверьте оба случая.

### Шаг 6. Расшифруйте набор

Соберите список имён, у которых флаг установлен:

```python
names = []
for name, flag in FLAGS.items():
    if has(rights, flag):
        names.append(name)
```

Для 29 ожидается `READ, EXEC, DELETE, ADMIN`.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| значение 0 | прав нет |
| значение 31 | все права |
| снятие отсутствующего флага | число не меняется |
| установка существующего | число не меняется |
| лишний бит 64 | не считается известным правом |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, таблица операций, двоичные записи, расшифровка, вывод. Вставьте скриншот.
