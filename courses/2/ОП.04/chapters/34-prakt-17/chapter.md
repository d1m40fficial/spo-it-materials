## Что требуется

Написать программу `import_catalog.py`, которая читает `catalog.json` и загружает каталог. Программа:

1. читает массив объектов;
2. проверяет обязательные поля;
3. отбрасывает некорректные записи;
4. считает число позиций и общую стоимость;
5. фильтрует по категории.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Рассмотрите JSON

Откройте `catalog.json`. Это массив объектов. У корректной записи есть `name`, `price`, `quantity` и `category`. Некоторые записи намеренно испорчены.

### Шаг 2. Прочитайте файл

```python
import json

with open("catalog.json", encoding="utf-8") as f:
    raw = json.load(f)
```

Проверьте, что верхний уровень это список. Если пришёл словарь, программа должна сообщить об ошибке структуры.

### Шаг 3. Проверьте записи

Для каждой записи проверьте:

- есть ли `name`, `price`, `quantity`, `category`;
- является ли `price` числом;
- больше ли `price` нуля;
- является ли `quantity` целым неотрицательным.

Некорректную запись не добавляйте в результат, но сохраните причину отказа.

### Шаг 4. Постройте каталог

Соберите список словарей с проверенными полями. При желании превратите записи в объекты класса `Product` из предыдущих практик.

Посчитайте число принятых и отброшенных записей. Для исходного файла ожидается 4 принятых и 2 отброшенных.

### Шаг 5. Считайте итоги

Для каждой записи стоимость равна `price * quantity`. Выведите:

- общую стоимость;
- самую дорогую позицию;
- среднюю цену.

### Шаг 6. Фильтр по категории

Соберите записи категории `посуда`. Проверьте, что фильтр не меняет исходный список.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустой массив | 0 записей, сумма 0 |
| одна корректная запись | 1 принята |
| отсутствует поле | запись отброшена |
| отрицательная цена | запись отброшена |
| `price` строкой | запись отброшена |
| верхний уровень не массив | сообщение об ошибке |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, результаты, таблица отброшенных записей, вывод о проверке данных. Вставьте скриншот.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или читает данные без проверки |
| 3 | Импорт работает, но часть некорректных записей проходит |
| 4 | Все проверки выполнены, итоги верны, отчёт заполнен |
