## Одно число вместо пяти галочек

У пользователя есть права: читать, писать, выполнять, удалять и администрировать. Можно хранить пять отдельных `True` и `False`, а можно одно число, в битах которого закодированы признаки.

```python
READ = 1      # 00001
WRITE = 2     # 00010
EXEC = 4      # 00100
DELETE = 8    # 01000
ADMIN = 16    # 10000

rights = READ | WRITE
print(rights)
```

```text
3
```

Число 3 это `00011`: биты чтения и записи включены. Проверка права занимает одну операцию:

```python
print(rights & WRITE)     # 2, право есть
print(rights & EXEC)      # 0, права нет
```

Одно число компактнее пяти переменных, а проверка не требует перебора.

Главная мысль занятия: **бит это минимальная единица информации, а маска это число, которое выбирает нужные биты**. Операции над битами позволяют хранить наборы признаков и быстро их проверять.

## Двоичная запись

В десятичной записи разряды означают степени десяти. В двоичной каждая позиция означает степень двойки:

| Разряд | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Бит | 0 | 0 | 1 | 0 | 1 | 1 | 0 | 1 |

Число `00101101` равно `32 + 8 + 4 + 1 = 45`. Младший бит стоит справа, старший слева.

```python
print(bin(45))
print(int("101101", 2))
print(45 & 1)
```

```text
0b101101
45
1
```

`bin` возвращает строку с префиксом `0b`. `int(..., 2)` разбирает двоичную запись. `45 & 1` проверяет младший бит: для чётного числа он равен 0, для нечётного 1.

## Операции

**И (`&`)** оставляет единицу только там, где она есть в обоих числах. Это чтение по маске.

```python
45 & 15   # 13, остаются младшие четыре бита
```

**ИЛИ (`|`)** ставит единицу, если она есть хотя бы в одном числе. Это установка флагов.

```python
45 | 128  # 173, включает старший бит
```

**Исключающее ИЛИ (`^`)** переключает бит: 1 меняется на 0, 0 на 1.

```python
45 ^ 15   # 34
```

**НЕ (`~`)** инвертирует все биты. В Python числа бесконечной длины, поэтому `~x` равно `-x - 1`. Для маскирования используют `& ~mask`, а не `~mask` отдельно.

**Сдвиги** двигают разряды:

```python
print(45 << 1)   # 90, умножение на 2
print(45 >> 1)   # 22, деление на 2 без остатка
```

Сдвиг влево добавляет нули справа. Сдвиг вправо отбрасывает младшие биты.

## Флаги и маски

Флаг это отдельный бит с именем. Маска это число, в котором нужные флаги включены.

```python
READ = 1
WRITE = 2
EXEC = 4

def has(value, flag):
    return (value & flag) != 0

rights = READ | WRITE
print(has(rights, READ))
print(has(rights, EXEC))
```

```text
True
False
```

Установка, снятие и переключение:

```python
rights |= EXEC       # установить
rights &= ~WRITE     # снять
rights ^= READ       # переключить
```

Проверка `(value & flag) != 0` важнее, чем `value & flag == True`. Результат `&` это число, а не логическое значение. Для флага с весом 2 выражение вернёт 2, и сравнение с `True` даст `False`.

## Где биты ломаются

**Путаница `&` и `|`.** `&` оставляет общее, `|` объединяет. Проверка: подставьте маску с одним битом.

**Сравнение с `True`.** `value & flag` возвращает число. Исправление: `(value & flag) != 0`.

**Забытое отрицание при снятии.** `value &= mask` оставит только биты маски, а не снимет их. Исправление: `value &= ~mask`.

**Сдвиг на отрицательное число.** Python выдаёт `ValueError`. Проверка: сдвиг должен быть неотрицательным.

**Нумерация битов.** Бит 0 это вес 1, бит 3 это вес 8. Проверка: `1 << n` даёт маску для бита `n`.

**Отрицательные числа.** В дополнительном коде старшие биты заполнены единицами, поэтому `~` и `>>` ведут себя не так, как для беззнаковых чисел.

> [!PITFALL] Битовая маска не заменяет проверку данных. Если флаг пришёл из внешнего источника, убедитесь, что число не содержит лишних разрядов.

## Итоги

- Двоичная запись показывает, какие степени двойки включены в число.
- `&` читает биты по маске, `|` устанавливает, `^` переключает.
- `value & flag != 0` проверяет флаг, `value |= flag` ставит его.
- Снятие флага выполняется через `value &= ~flag`.
- Сдвиг влево умножает на два, вправо делит на два без остатка.
