## Что требуется

Написать программу `pipeline.py`, которая обрабатывает список заказов конвейером. Каждый этап это генератор.

Программа:

1. отбирает оплаченные заказы;
2. отбрасывает суммы ниже порога;
3. считает количество и сумму;
4. выводит первые три записи;
5. показывает, что генератор проходится один раз.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает заказы и нулевые итоги. Пока в файле `TODO`, конвейер пуст.

### Шаг 2. Фильтр по статусу

```python
def paid(orders):
    for order in orders:
        if order["status"] == "оплачен":
            yield order
```

Генератор не создаёт список, а выдаёт записи по одной. Для исходных данных ожидается 4 оплаченных заказа.

### Шаг 3. Фильтр по сумме

```python
def above(orders, limit):
    for order in orders:
        if order["amount"] >= limit:
            yield order
```

Порог 500. После двух фильтров остаются заказы с суммами 1200, 2500 и 1700.

### Шаг 4. Преобразование

Добавьте этап, который превращает запись в строку отчёта или добавляет поле.

```python
def with_vat(orders):
    for order in orders:
        yield {**order, "vat": order["amount"] * 0.2}
```

Новый словарь создаётся, исходная запись не меняется.

### Шаг 5. Ограничение

```python
def first_n(items, n):
    count = 0
    for item in items:
        if count >= n:
            return
        yield item
        count += 1
```

Для первых двух записей ожидаются суммы 1200 и 2500.

### Шаг 6. Соберите конвейер

```python
stream = first_n(above(paid(orders), 500), 3)
for order in stream:
    print(order)
```

Каждый этап получает данные от предыдущего. Списки не создаются.

### Шаг 7. Проверьте однократность

Создайте генератор, пройдите его один раз и попробуйте пройти снова. Второй проход должен быть пустым. Это не ошибка, а свойство генератора.

Чтобы получить два отчёта, создайте конвейер заново.

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код этапов, результаты, таблица проверок, вывод о ленивых вычислениях. Вставьте скриншот.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или этапы отсутствуют |
| 3 | Фильтры работают, но конвейер или итоги неверны |
| 4 | Все части решены, проверки выполнены, отчёт заполнен |
| 5 | Все части и границы выполнены, ленивость объяснена |
