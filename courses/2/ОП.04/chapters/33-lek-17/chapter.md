## Один заказ, два файла

Интернет-магазин передаёт заказ в бухгалтерию. Программист может сохранить его двумя способами.

Первый файл:

```json
{
  "order": 7,
  "paid": true,
  "customer": {"name": "Анна", "city": "Тверь"},
  "items": [
    {"name": "Кружка", "price": 640},
    {"name": "Блюдце", "price": 420}
  ]
}
```

Второй файл:

```text
order;customer;city;item;price
7;Анна;Тверь;Кружка;640
7;Анна;Тверь;Блюдце;420
```

Оба файла содержат одни данные, но устроены по-разному. JSON повторяет структуру: заказ, покупатель, список товаров. CSV выпрямляет её в таблицу и повторяет данные заказа в каждой строке.

Главная мысль занятия: **формат выбирают по структуре данных и по тому, кто будет их читать**. Вложенный объект удобно передать в JSON. Таблицу удобно открыть в Excel, и для неё лучше CSV.

## Синтаксис JSON

JSON состоит из шести видов значений:

| Значение | Пример |
|---|---|
| объект | `{"name": "Кружка"}` |
| массив | `[640, 420]` |
| строка | `"Тверь"` |
| число | `640`, `12.5` |
| логическое | `true`, `false` |
| пустое | `null` |

Объект это набор пар «ключ: значение» в фигурных скобках. Массив это список в квадратных скобках. Ключи всегда строки в двойных кавычках.

После разбора JSON превращается в обычные объекты Python:

- объект в `dict`;
- массив в `list`;
- строка в `str`;
- число в `int` или `float`;
- `true` и `false` в `bool`;
- `null` в `None`.

## Чтение JSON

```python
import json

with open("order.json", encoding="utf-8") as f:
    order = json.load(f)

print(order["order"])
print(order["customer"]["city"])
print(order["items"][0]["price"])
```

```text
7
Тверь
640
```

`json.load` читает файл, `json.loads` разбирает строку. Обратная операция: `json.dump` пишет в файл, `json.dumps` возвращает строку.

Вложенность читается цепочкой ключей и индексов. Если ключа нет, возникает `KeyError`. Если структура не совпала, например вместо списка пришёл словарь, возникнет `TypeError` или `IndexError`.

Проверять наличие ключа лучше через `get`:

```python
city = order.get("customer", {}).get("city", "не указан")
```

Запись JSON:

```python
with open("order.json", "w", encoding="utf-8") as f:
    json.dump(order, f, ensure_ascii=False, indent=2)
```

`ensure_ascii=False` сохраняет русские буквы как есть. `indent=2` делает файл читаемым. Без отступа JSON записывается в одну строку.

## CSV

CSV это текст, где строки разделены переводом строки, а поля разделителем. Первая строка обычно содержит заголовки.

```text
name;price;quantity
Кружка;640;3
Блюдце;420;2
```

Модуль `csv` учитывает кавычки и разделители внутри полей:

```python
import csv

with open("catalog.csv", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f, delimiter=";")
    for row in reader:
        print(row["name"], int(row["price"]) * int(row["quantity"]))
```

```text
Кружка 1920
Блюдце 840
```

`newline=""` обязателен при работе с CSV на Windows. Без него модуль может добавить лишние пустые строки.

Все значения из CSV приходят строками. Числа нужно преобразовывать явно:

```python
price = float(row["price"])
quantity = int(row["quantity"])
```

Если в файле десятичная запятая `640,50`, преобразование в `float` упадёт. Исправление: заменить запятую на точку или использовать другой разделитель полей.

Запись CSV:

```python
with open("report.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, delimiter=";")
    writer.writerow(["name", "total"])
    writer.writerow(["Кружка", "1920.00"])
```

`writerow` добавляет перевод строки сам. Заголовок пишется первой строкой.

## JSON или CSV

| Критерий | JSON | CSV |
|---|---|---|
| Вложенность | поддерживает | нет |
| Типы | сохраняются | всё строки |
| Читать человеку | удобно с отступами | удобно в таблице |
| Excel | не открывает напрямую | открывает |
| Размер | больше из-за ключей | компактнее |
| API | стандарт обмена | редко |

Если данные представляют собой таблицу с одинаковыми колонками, CSV проще. Если у записей разная структура или есть вложенные объекты, JSON точнее.

JSON не хранит даты и множества. Дата записывается строкой, множество превращается в список. При чтении нужно восстановить тип самостоятельно.

## Ошибки формата

**`json.JSONDecodeError`.** В файле лишняя запятая, одинарные кавычки или комментарий. JSON не разрешает комментарии и требует двойные кавычки. Проверка: откройте файл и посмотрите на строку из сообщения.

**`KeyError`.** Ключа нет в словаре. Исправление: `get` с запасным значением или проверка `in`.

**`UnicodeDecodeError`.** Файл сохранён в одной кодировке, а прочитан в другой. Указывайте `encoding="utf-8"` и следите, чтобы источник сохранял файл в UTF-8.

**Неверный разделитель.** CSV с запятой прочитан с `delimiter=";"`, и вся строка попала в одно поле. Проверка: напечатайте первую строку и число полей.

**Лишние пустые строки.** Открыли CSV без `newline=""`. Исправление: добавить параметр.

**Потеря типов.** `"10" + "5"` даёт `"105"`, а не `15`. Преобразуйте поля до арифметики.

> [!PITFALL] JSON и Python похожи, но это разные языки. В JSON нет `True`, `None` и одинарных кавычек. Запись `{'a': 1}` не является корректным JSON.

## Итоги

- JSON хранит объекты, массивы, строки, числа, логические значения и `null`.
- `json.load` и `json.loads` превращают JSON в словари и списки, типы сохраняются.
- CSV это таблица с заголовком; все поля приходят строками.
- Для CSV нужны `encoding="utf-8"` и `newline=""`, числа преобразуют явно.
- Формат выбирают по структуре: вложенность это JSON, таблица это CSV.
