## Что требуется

Собрать расчёт заказов из двух файлов:

- `pricing.py` содержит функции расчёта;
- `starter.py` подключает их и печатает чеки.

Функции:

1. `order_total(price, quantity, discount)` считает стоимость товаров со скидкой.
2. `delivery_cost(total, zone)` считает доставку.
3. `format_receipt(...)` собирает строку чека.

Затем проверяется запуск модуля отдельно и работа импорта. Код и результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите оба файла

```bash
python pricing.py
python starter.py
```

`pricing.py` печатает самопроверку. `starter.py` печатает пустые чеки, пока функции не заполнены. Ошибка `ImportError` означает, что файлы лежат в разных папках.

### Шаг 2. Функция order_total

Функция принимает цену, количество и скидку в процентах. Порядок расчёта:

1. сумма без скидки: `price * quantity`;
2. размер скидки: `subtotal * discount / 100`;
3. итог: `subtotal - discount_value`.

Скидка не должна делать итог отрицательным. Если скидка больше 100 процентов, верните `0.0`. Проверьте:

```text
order_total(640, 3, 10) = 1728.0
order_total(40, 10, 5) = 380.0
order_total(100, 1, 0) = 100.0
order_total(100, 1, 150) = 0.0
```

Функция возвращает число, а не печатает его. Это важно: результат нужен для дальнейших расчётов.

### Шаг 3. Функция delivery_cost

Доставка зависит от зоны:

| Зона | Стоимость |
|---|---:|
| город | 300, при сумме от 3000 бесплатно |
| область | 500 |
| самовывоз | 0 |

Постройте лестницу условий. Неизвестную зону считайте самовывозом или выдавайте ошибку: выберите один вариант и объясните его в отчёте.

Проверьте `delivery_cost(1728)` и `delivery_cost(4500)`. В первом случае ожидается 300, во втором 0.

### Шаг 4. Строка чека

`format_receipt` возвращает строку вида:

```text
Заказ 1. Кружка: 1728.00 + доставка 300.00 = 2028.00
```

Формат чисел задайте через `:.2f`. Функция не должна печатать: печать выполняет вызывающий код. Так строку можно записать в файл или сравнить в проверке.

### Шаг 5. Подключение модуля

В `starter.py` уже есть строка:

```python
from pricing import order_total, delivery_cost
```

Убедитесь, что функции действительно лежат в `pricing.py`, а не в `starter.py`. Если перенести их обратно, импорт перестанет работать.

Сравните два варианта импорта:

```python
import pricing
total = pricing.order_total(640, 3, 10)
```

и

```python
from pricing import order_total
total = order_total(640, 3, 10)
```

Первый вариант показывает источник функции. Второй короче. Запишите в отчёт, какой вариант вы выбрали и почему.

### Шаг 6. Самопроверка модуля

Блок `if __name__ == "__main__"` в `pricing.py` выполняется только при прямом запуске. При импорте он молчит.

Проверьте это:

1. запустите `python pricing.py`, увидите строки самопроверки;
2. запустите `python starter.py`, строк самопроверки быть не должно.

Если строки появились в обоих случаях, проверка записана неверно.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| количество 0 | итог 0.0 |
| скидка 0 | итог равен сумме |
| скидка 100 | итог 0.0 |
| сумма ровно 3000 | доставка 0 |
| сумма 2999 | доставка 300 |
| пустой список заказов | итог 0.0 |

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код обоих файлов.
3. Результаты функций.
4. Таблица проверок.
5. Вывод о разделении на модули.

Вставьте скриншот двух запусков: `pricing.py` и `starter.py`.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или выполнено меньше половины частей |
| 3 | Функции работают, но импорт или проверка `__main__` выполнены неверно |
| 4 | Все части решены, проверки выполнены, отчёт заполнен, есть мелкие недочёты |
| 5 | Все части решены, границы проверены, структура модуля объяснена |

## Что сдаётся

- `pricing.py` и `starter.py`.
- `report.docx` с кодом, результатами и проверками.
- Скриншоты запуска обоих файлов.

> [!PITFALL] Если функция печатает результат вместо `return`, её нельзя использовать в расчёте. `total = order_total(...)` получит `None`, и следующая строка упадёт с `TypeError`.
