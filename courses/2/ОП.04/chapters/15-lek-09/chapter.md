## Два списка и один вопрос

В программе есть список товаров и список цен:

```python
names = ["кружка", "блюдце", "коробка"]
prices = [640, 420, 40]
```

Чтобы узнать цену кружки, нужно найти её индекс в первом списке и взять элемент с тем же индексом во втором:

```python
i = names.index("кружка")
print(prices[i])
```

Пока товаров три, это работает. Когда их станет тысяча, поиск индекса будет перебирать список снова и снова. Кроме того, списки легко рассинхронизировать: добавили товар в один, забыли в другой, и все цены после этого сместились.

Словарь хранит связь напрямую:

```python
prices = {"кружка": 640, "блюдце": 420, "коробка": 40}
print(prices["кружка"])
```

```text
640
```

Теперь не нужно помнить позицию. Ключ сам находит значение. Вторая структура занятия решает другую задачу: хранит только уникальные элементы. Если нужно узнать, какие товары встречаются в двух заказах, множество отвечает на это одной операцией.

Главная мысль занятия: **структуру выбирают по вопросу, на который она отвечает**. «Какое значение соответствует ключу» это словарь. «Какие элементы общие, а какие только у одного набора» это множество.

## Словарь

Словарь записывают в фигурных скобках, пары разделяют запятыми, ключ и значение соединяют двоеточием.

```python
prices = {
    "кружка": 640,
    "блюдце": 420,
    "коробка": 40,
}
```

Ключи уникальны. Если записать один ключ дважды, останется последнее значение. Значения могут повторяться.

Обращение по ключу:

```python
print(prices["блюдце"])
```

Если ключа нет, возникает `KeyError`:

```python
print(prices["чашка"])
```

```text
KeyError: 'чашка'
```

Безопасный способ получить значение с запасным вариантом это `get`:

```python
print(prices.get("чашка", 0))
```

```text
0
```

`get` не создаёт ключ. Если нужно, чтобы ключ появился со значением по умолчанию, используют `setdefault`.

Добавление и обновление выглядят одинаково:

```python
prices["чашка"] = 950
prices["кружка"] = 610
```

Если ключа не было, он создаётся. Если был, значение заменяется.

Удаление выполняют через `del` или `pop`:

```python
del prices["коробка"]
price = prices.pop("блюдце")
```

`pop` возвращает удалённое значение, поэтому его удобно сохранить.

## Перебор словаря

Словарь можно перебирать тремя способами.

```python
prices = {"кружка": 640, "блюдце": 420, "коробка": 40}

for key in prices:
    print(key)

for value in prices.values():
    print(value)

for key, value in prices.items():
    print(key, value)
```

Первый цикл перебирает ключи, второй значения, третий пары. В учебных задачах чаще всего нужен третий вариант.

Порядок элементов сохраняется таким, в каком ключи были добавлены. Это не «сортировка по алфавиту» и не «по значению». Если нужен порядок по значению, словарь сортируют отдельно:

```python
sorted_prices = sorted(prices.items(), key=lambda pair: pair[1])
print(sorted_prices)
```

```text
[('коробка', 40), ('блюдце', 420), ('кружка', 640)]
```

`items()` даёт пары, `sorted` сортирует их по второму элементу. Результат это список кортежей, а не словарь.

Проверка наличия ключа выполняется через `in`:

```python
print("кружка" in prices)
print("чашка" in prices)
```

```text
True
False
```

`in` проверяет ключи, а не значения. Чтобы проверить значение, перебирают `values()`.

## Множества

Множество хранит уникальные элементы без порядка. Записывают его через `set()` или фигурные скобки без двоеточий.

```python
tags = {"срочно", "доставка", "срочно"}
print(tags)
print(len(tags))
```

```text
{'срочно', 'доставка'}
2
```

Повтор при добавлении не создаёт второй элемент. Это главное свойство множества.

Пустое множество создают только через `set()`. Запись `{}` создаёт пустой словарь, а не множество.

```python
empty_set = set()
empty_dict = {}
```

Добавление и удаление:

```python
tags.add("самовывоз")
tags.discard("доставка")
```

`discard` не выдаёт ошибку, если элемента нет. `remove` в таком случае выдаёт `KeyError`.

Операции над множествами:

| Операция | Запись | Что даёт |
|---|---|---|
| Пересечение | `a & b` | элементы, которые есть в обоих |
| Объединение | `a.union(b)` | все элементы без повторов |
| Разность | `a - b` | элементы `a`, которых нет в `b` |
| Симметричная разность | `a ^ b` | элементы, которые есть только в одном |

```python
a = {"кружка", "блюдце", "чайник"}
b = {"блюдце", "коробка", "ложка"}

print(a & b)
print(a | b)
print(a - b)
print(a ^ b)
```

```text
{'блюдце'}
{'кружка', 'блюдце', 'чайник', 'коробка', 'ложка'}
{'кружка', 'чайник'}
{'кружка', 'чайник', 'коробка', 'ложка'}
```

Порядок в выводе может отличаться: множество не гарантирует порядок. Сравнивать результаты нужно по составу, а не по строке.

Проверка вложенности:

```python
print({"блюдце"} <= a)
print(a.isdisjoint(b))
```

`<=` проверяет, что одно множество целиком входит в другое. `isdisjoint` истинно, если общих элементов нет.

## Словарь или множество

Выбор структуры зависит от вопроса.

| Вопрос | Структура |
|---|---|
| Какая цена у товара | словарь |
| Сколько раз встретилось слово | словарь |
| Какие слова встретились | множество |
| Какие товары есть в обоих заказах | множество |
| Какие товары только в первом заказе | множество |
| Какие товары и их количество | словарь |

Часто структуры работают вместе. Частотный словарь строится так:

```python
words = ["кружка", "блюдце", "кружка", "чашка", "кружка"]
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts)
```

```text
{'кружка': 3, 'блюдце': 1, 'чашка': 1}
```

`get(word, 0)` возвращает текущее число или ноль, если слова ещё нет. Затем к нему прибавляется единица и результат записывается обратно. Это стандартный приём подсчёта частот.

## Где словари и множества ломаются

**`KeyError` вместо значения.** Ключа нет в словаре. Исправление: `get` с запасным значением или проверка `in`.

**Изменение словаря во время перебора.** Нельзя удалять ключи внутри `for key in prices`. Исправление: собрать список ключей или новый словарь.

**Изменяемый ключ.** Ключом может быть строка, число или кортеж, но не список. Список не хешируется, поэтому Python выдаёт `TypeError`.

**`{}` вместо пустого множества.** Фигурные скобки без элементов создают словарь. Используйте `set()`.

**Ожидание порядка в множестве.** Порядок вывода не гарантирован. Если он важен, результат сортируют.

**Сравнение множеств как строк.** `print(a)` может вывести элементы в другом порядке. Сравнивайте сами множества через `==`, а не их текстовое представление.

> [!PITFALL] `prices.get("чашка")` возвращает `None`, а не создаёт ключ. Если потом обратиться к `prices["чашка"]`, всё равно будет `KeyError`.

## Итоги

- Словарь хранит пары ключ-значение и ищет значение по ключу.
- `get` безопасно возвращает значение или запасной вариант.
- Перебор идёт по ключам, значениям или парам через `items()`.
- Множество хранит уникальные элементы и поддерживает пересечение, объединение и разность.
- Структуру выбирают по вопросу: соответствие это словарь, уникальность и сравнение наборов это множество.
