## Почему `"5" + 2` не работает

Введите в Python две строки:

```python
x = "5"
print(x + 2)
```

Интерпретатор остановится с ошибкой:

```text
TypeError: can only concatenate str (not "int") to str
```

Слева стоит строка, справа число. Операция `+` умеет складывать числа и склеивать строки, но не умеет смешивать их без явного преобразования. Если написать `int(x) + 2`, получится `7`, потому что `int(x)` создаёт новое число из текста.

Эта ошибка полезна. Она показывает главное правило: **значение имеет тип, и тип определяет, какие операции допустимы**. Переменная это не коробка с надписью, а имя, которое указывает на значение. Когда имя начинает указывать на значение другого типа, меняется и поведение программы.

## Имя и значение

Присваивание связывает имя со значением:

```python
x = 5
print(type(x))
```

Вывод:

```text
<class 'int'>
```

Строка `x = 5` не «создаёт число 5 в переменной». Она создаёт объект числа 5 и связывает с ним имя `x`. Если затем выполнить `x = "пять"`, имя `x` начнёт указывать на строку, а старое число исчезнет, когда на него не останется ссылок.

```python
x = 5
x = "пять"
print(type(x))
```

```text
<class 'str'>
```

Python используют динамическую типизацию: тип определяется значением, а не объявлением имени. Это удобно для коротких программ, но требует внимательности. Одно и то же имя в разных местах может хранить разные типы, и ошибка проявляется только при операции.

Имена переменных подчиняются правилам:

- начинаются с буквы или `_`, а не с цифры;
- содержат буквы, цифры и `_`;
- не совпадают с ключевыми словами вроде `if`, `for`, `class`;
- читаются как слова: `price`, `quantity`, `total`, а не `a1`, `b2`, `c3`.

Регистр важен: `Price` и `price` это разные имена.

## Пять базовых типов

Для первых программ достаточно пяти типов.

| Тип | Пример | Что хранит | Частая операция |
|---|---|---|---|
| `int` | `5`, `-12`, `0` | целое число | `+`, `-`, `*`, `//`, `%` |
| `float` | `3.14`, `0.5`, `-2.0` | дробное число | `+`, `-`, `*`, `/` |
| `str` | `"5"`, `"Кружка"` | текст | `+`, `*`, `len`, срезы |
| `bool` | `True`, `False` | истина или ложь | `and`, `or`, `not` |
| `None` | `None` | отсутствие значения | сравнение `is None` |

`type(x)` возвращает тип значения. Это не преобразование, а вопрос «что здесь лежит». Сравните:

```python
print(type(5))
print(type("5"))
print(type(5.0))
print(type(True))
```

```text
<class 'int'>
<class 'str'>
<class 'float'>
<class 'bool'>
```

`bool` это подтип `int`: `True` ведёт себя как `1`, а `False` как `0`. Но смешивать логические значения с числами без необходимости не стоит, иначе код становится трудно читать.

## Операции

Арифметические операции работают по-разному для чисел.

| Операция | Пример | Результат | Что делает |
|---|---|---:|---|
| `+` | `7 + 2` | `9` | сложение |
| `-` | `7 - 2` | `5` | вычитание |
| `*` | `7 * 2` | `14` | умножение |
| `/` | `7 / 2` | `3.5` | деление, всегда `float` |
| `//` | `7 // 2` | `3` | целая часть деления |
| `%` | `7 % 2` | `1` | остаток |
| `**` | `2 ** 3` | `8` | степень |

Деление `/` всегда возвращает `float`, даже если числа делятся нацело. `10 / 2` даёт `5.0`, а не `5`. Для количества денег это нормально, для количества предметов может потребоваться `//`.

Строки поддерживают `+` и `*`:

```python
print("Кружка" + " 300 мл")
print("=" * 12)
```

```text
Кружка 300 мл
============
```

`+` склеивает строки, `*` повторяет строку. Число и строка без преобразования не складываются.

Сравнения возвращают `bool`:

```python
print(7 > 2)
print(7 == 7)
print("5" == 5)
```

```text
True
True
False
```

Последняя строка важна: строка `"5"` и число `5` не равны. Совпадение символов не делает значения одним и тем же типом.

Логические операции соединяют условия:

```python
age = 18
has_ticket = True
print(age >= 18 and has_ticket)
print(not has_ticket)
```

```text
True
False
```

`and` возвращает истину, только если истинны оба операнда. `or` возвращает истину, если истинен хотя бы один. `not` переворачивает значение. В Python `and` и `or` вычисляют второй операнд только при необходимости, но для первых программ достаточно понимать таблицу истинности.

## Приоритет операций

Выражение вычисляется не слева направо, а по приоритетам. Сначала степень, затем умножение и деление, затем сложение и вычитание, затем сравнения, затем `not`, `and`, `or`.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
```

```text
14
20
512
```

В первом выражении сначала выполняется `3 * 4`, потом прибавление. Во втором скобки меняют порядок. В третьем степень считается справа налево: `3 ** 2 = 9`, затем `2 ** 9 = 512`.

Скобки это не признак плохого кода, а способ сделать намерение явным. Если сомневаетесь, ставьте скобки. Читаемость важнее экономии двух символов.

## Преобразование типов

Преобразование создаёт значение другого типа. Основные функции:

| Функция | Пример | Результат | Когда нужна |
|---|---|---|---|
| `int(x)` | `int("5")` | `5` | текст или дробное в целое |
| `float(x)` | `float("3.14")` | `3.14` | текст в дробное |
| `str(x)` | `str(5)` | `"5"` | число в текст |
| `bool(x)` | `bool(0)` | `False` | проверить пустоту или ноль |

`int("5")` работает, потому что строка содержит целое число. `int("3.14")` выдаст `ValueError`: точка и дробная часть не являются целым числом. `int("3,14")` тоже ошибка, потому что в Python дробная часть отделяется точкой, а не запятой.

```python
print(int("5") + 2)
print(float("3.14") * 2)
print(str(5) + " рублей")
```

```text
7
6.28
5 рублей
```

`input()` всегда возвращает строку. Даже если пользователь ввёл `18`, программа получает `"18"`. Поэтому перед арифметикой ввод преобразуют:

```python
price = float(input("Цена: "))
quantity = int(input("Количество: "))
total = price * quantity
print(total)
```

Если пользователь введёт `12,50`, `float` выдаст `ValueError`. Это не поломка Python, а сигнал, что формат ввода не совпал с ожидаемым. В практической работе такие случаи проверяют отдельно.

## Форматирование вывода

Для денег и измерений важно не только посчитать, но и показать результат с нужным числом знаков. `f`-строка вставляет значение в текст и позволяет задать формат.

```python
price = 640.0
quantity = 3
discount = 10
subtotal = price * quantity
discount_value = subtotal * discount / 100
total = subtotal - discount_value
print(f"Сумма: {subtotal:.2f}")
print(f"Скидка: {discount_value:.2f}")
print(f"Итого: {total:.2f}")
```

```text
Сумма: 1920.00
Скидка: 192.00
Итого: 1728.00
```

`.2f` означает «два знака после точки». Это формат вывода, а не изменение самого числа. `round(total, 2)` тоже округляет, но при печати без формата `1728.0` может выглядеть как `1728.0`, а не как денежная сумма.

Для целых величин используйте `:.0f` или `int`, если дробная часть не нужна. Для процентов можно использовать `:.1f` и добавить знак `%` в текст.

## Где возникают ошибки типов

**Сложение строки и числа.** `"5" + 2` даёт `TypeError`. Исправление: `int("5") + 2` или `"5" + str(2)`.

**Забытое преобразование ввода.** `input()` возвращает строку, поэтому `price * quantity` даёт повтор строки, а не произведение. Исправление: `float(input(...))` и `int(input(...))`.

**Деление на ноль.** `7 / 0` даёт `ZeroDivisionError`. Проверяйте делитель до операции.

**Путаница `=` и `==`.** `x = 5` присваивает, `x == 5` сравнивает. В условии нужно сравнение.

**Неверный разделитель дробной части.** `float("3,14")` не работает. Исправление: заменить запятую на точку или использовать `replace(",", ".")`.

**Целочисленное деление вместо обычного.** `7 / 2` даёт `3.5`, `7 // 2` даёт `3`. Выбирайте операцию по смыслу задачи.

> [!PITFALL] `bool("False")` равно `True`, потому что непустая строка считается истинной. Для логического значения из текста нужна отдельная проверка, а не `bool`.

## Итоги

- Переменная связывает имя со значением, а тип значения определяет допустимые операции.
- Пять базовых типов: `int`, `float`, `str`, `bool`, `None`.
- `input()` возвращает строку, поэтому перед расчётом её преобразуют в число.
- Приоритет операций задаёт порядок вычисления, скобки делают намерение явным.
- `f`-строка с форматом `.2f` печатает деньги и измерения с нужным числом знаков.
