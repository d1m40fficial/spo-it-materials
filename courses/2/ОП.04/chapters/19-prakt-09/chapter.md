## Что требуется

Написать программу `log_report.py`, которая читает журнал `log.csv` и строит сводку:

1. сколько непустых строк в файле;
2. разбор каждой строки на время, уровень и сообщение;
3. количество записей каждого уровня;
4. список сообщений об ошибках;
5. файл `report.txt` с итогами.

Журнал приложен к практике. Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Проверьте файл

Откройте `log.csv` в VS Code. Убедитесь, что каждая строка содержит три поля, разделённые точкой с запятой:

```text
2026-11-18 09:12:01;INFO;Запуск
```

Файл сохранён в UTF-8. Если при чтении появится `UnicodeDecodeError`, проверьте кодировку файла.

### Шаг 2. Посчитайте строки

Откройте файл через контекстный менеджер:

```python
with open("log.csv", encoding="utf-8") as f:
    for line in f:
        ...
```

Считайте только непустые строки. Для журнала из задания их 7. Не используйте `readlines`, если хотите отработать построчное чтение.

### Шаг 3. Разберите строку

Уберите перевод строки через `strip`, затем разделите поля:

```python
parts = line.split(";", 2)
```

Третий аргумент ограничивает число делений. Если сообщение содержит точку с запятой, она останется в третьем поле.

Проверьте, что после разбора получилось три части. Строку с другим числом полей пропускайте и считайте отдельно.

### Шаг 4. Сводка по уровням

Заполните словарь:

```python
counts[level] = counts.get(level, 0) + 1
```

Для журнала ожидается:

| Уровень | Количество |
|---|---:|
| INFO | 4 |
| WARNING | 1 |
| ERROR | 2 |

Выведите уровни в отсортированном порядке, чтобы вывод не зависел от порядка появления.

### Шаг 5. Фильтр ошибок

Соберите сообщения строк с уровнем `ERROR`. Ожидается два сообщения: о ненайденном файле и о запрете доступа.

Отфильтруйте их одним циклом, не читая файл повторно. Повторное чтение допустимо, но менее эффективно и требует снова открывать файл.

### Шаг 6. Запишите отчёт

Создайте `report.txt` в режиме `"w"`:

```python
with open("report.txt", "w", encoding="utf-8") as out:
    out.write(f"Всего строк: {total}\n")
    for level in sorted(counts):
        out.write(f"{level}: {counts[level]}\n")
```

Каждая строка заканчивается `\n`, потому что `write` не добавляет перевод сам. После запуска откройте файл и проверьте содержимое.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустая строка в журнале | пропускается, счётчик не растёт |
| строка без двух точек с запятой | пропускается с сообщением |
| файл отсутствует | сообщение об ошибке, программа не падает |
| повторный запуск | `report.txt` перезаписывается |
| другой уровень | попадает в сводку отдельной строкой |

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код.
3. Результаты пяти частей.
4. Таблица проверок.
5. Вывод: зачем нужен `strip` перед разбором.

Вставьте скриншот запуска и содержимое `report.txt`.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или выполнено меньше половины частей |
| 3 | Файл читается, но разбор или сводка содержат ошибки |
| 4 | Все части решены, проверки выполнены, отчёт заполнен, есть мелкие недочёты |
| 5 | Все части решены, границы проверены, отчёт читается без пояснений |
