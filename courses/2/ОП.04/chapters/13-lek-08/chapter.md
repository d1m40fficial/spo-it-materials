## Один расчёт в трёх местах

В программе магазина скидку считают трижды: в чеке, в отчёте за день и в письме клиенту. Код выглядит почти одинаково:

```python
subtotal = price * quantity
discount_value = subtotal * discount / 100
total = subtotal - discount_value
```

Пока правило не меняется, всё работает. Затем появляется условие: при сумме меньше 1000 скидка не применяется. Программист исправляет первое место и забывает второе. Чек считает правильно, отчёт расходится с чеком на несколько рублей, и найти причину трудно, потому что формулы выглядят одинаково.

Функция решает эту проблему:

```python
def apply_discount(subtotal, discount):
    if subtotal < 1000:
        return subtotal
    return subtotal - subtotal * discount / 100
```

Теперь правило записано в одном месте. Все три вызова обращаются к нему, и исправление автоматически действует везде.

Главная мысль занятия: **функция это имя для законченного действия, у которого есть вход, выход и один ответственный участок кода**. Модуль добавляет второй уровень: функции собираются в отдельный файл, который можно импортировать.

## Объявление и вызов

Функцию объявляют через `def`, затем имя, список параметров в скобках и двоеточие. Тело сдвинуто на четыре пробела.

```python
def greet(name):
    print("Привет,", name)

greet("Анна")
greet("Игорь")
```

```text
Привет, Анна
Привет, Игорь
```

`name` в объявлении это **параметр**, а `"Анна"` в вызове это **аргумент**. При вызове аргумент копируется в параметр, и тело выполняется с этим значением.

Функция без параметров объявляется с пустыми скобками:

```python
def show_rule():
    print("=" * 40)

show_rule()
```

Если функции нужен результат, его возвращают через `return`:

```python
def rectangle_area(a, b):
    return a * b

area = rectangle_area(3, 5)
print(area)
```

```text
15
```

`return` завершает функцию и передаёт значение в место вызова. После `return` остальные строки тела не выполняются.

```python
def check(value):
    if value < 0:
        return "отрицательное"
    return "неотрицательное"
```

Второй `return` выполнится только тогда, когда первый не сработал. Это заменяет ветвление и часто читается лучше, чем вложенные `if`.

::figure function-call | Аргументы 1200 и 10 попадают в параметры, тело считает скидку, return возвращает 1080 в переменную total.

## print и return

Начинающие часто путают печать и возврат. Это разные действия.

```python
def area_print(a, b):
    print(a * b)

def area_return(a, b):
    return a * b

x = area_print(3, 5)
y = area_return(3, 5)
print("x =", x)
print("y =", y)
```

```text
15
x = None
y = 15
```

`area_print` печатает число, но ничего не возвращает. Значение, которое не вернули явно, равно `None`. Поэтому `x` получает `None`, и использовать его в расчётах нельзя.

Правило простое: если результат нужен другой части программы, используйте `return`. `print` нужен для показа человеку, а не для передачи данных.

Функция может вернуть несколько значений через кортеж:

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([4, 7, 2, 9])
print(low, high)
```

```text
2 9
```

Формально возвращается один кортеж, а распаковка разносит его по двум именам.

## Область видимости

Имена, созданные внутри функции, локальны. Снаружи они не видны.

```python
def calculate():
    internal = 42
    return internal

calculate()
print(internal)
```

```text
NameError: name 'internal' is not defined
```

Локальная переменная живёт, пока выполняется вызов. После возврата она исчезает. Это защищает программу: две функции могут использовать одно имя `total` и не мешать друг другу.

Глобальные имена видны внутри функции, но изменять их без объявления `global` не стоит. Такой код трудно проверять, потому что результат зависит от состояния всей программы.

```python
rate = 0.2

def with_rate(value):
    return value * rate
```

Функция читает `rate` снаружи. Если завтра ставка изменится, поведение функции тоже изменится без её вызова. Надёжнее передать ставку параметром:

```python
def with_rate(value, rate):
    return value * rate
```

Параметр делает зависимость явной. Это одно из главных правил проектирования функций.

## Параметры по умолчанию

Параметру можно задать значение по умолчанию:

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

print(greet("Анна"))
print(greet("Игорь", "Здравствуйте"))
```

```text
Привет, Анна!
Здравствуйте, Игорь!
```

Параметры со значением по умолчанию идут после обязательных. Вызов `greet()` без имени завершится ошибкой, потому что `name` обязателен.

Аргументы можно передавать по имени:

```python
print(greet(name="Анна", greeting="Добрый день"))
```

Именованные аргументы делают вызов понятнее, особенно когда параметров много.

Опасная ловушка связана с изменяемыми значениями по умолчанию:

```python
def add_item(item, box=[]):
    box.append(item)
    return box

print(add_item("а"))
print(add_item("б"))
```

```text
['а']
['а', 'б']
```

Список по умолчанию создаётся один раз при объявлении функции и сохраняется между вызовами. Если нужен новый список, используют `None`:

```python
def add_item(item, box=None):
    if box is None:
        box = []
    box.append(item)
    return box
```

## Стек вызовов

Когда функция вызывает другую функцию, вызовы образуют стек. Последний вызов находится на вершине, и он завершается первым.

::figure stack-trace | Интерактивная трассировка: нажимайте «Шаг» и следите, как кадры появляются в стеке и снимаются при возврате.

Трассировка показывает, почему рекурсивная функция возвращает результат постепенно. Вызов `factorial(3)` не может завершиться, пока не получит результат `factorial(2)`, а тот ждёт `factorial(1)`. Когда самый глубокий вызов возвращает единицу, стек начинает разворачиваться снизу вверх.

## Модули

Модуль это файл с кодом, который можно подключить к другой программе. Если функции расчёта лежат в `pricing.py`, их импортируют так:

```python
import pricing

total = pricing.apply_discount(1200, 10)
```

Обращение идёт через имя модуля. Это удобно, когда функций много и нужно видеть, откуда они взялись.

Можно импортировать конкретные имена:

```python
from pricing import apply_discount

total = apply_discount(1200, 10)
```

При таком импорте имя функции попадает в текущее пространство имён. Если в программе уже есть своя `apply_discount`, она будет перекрыта. Поэтому длинные модули чаще импортируют целиком.

Модуль можно запускать как программу и импортировать как библиотеку. Чтобы код запуска выполнялся только при прямом запуске, используют проверку:

```python
def apply_discount(subtotal, discount):
    if subtotal < 1000:
        return subtotal
    return subtotal - subtotal * discount / 100

if __name__ == "__main__":
    print(apply_discount(1200, 10))
```

При `python pricing.py` условие истинно и пример выполняется. При `import pricing` условие ложно, и печать не происходит. Это стандартный способ сделать модуль и библиотекой, и самостоятельной программой.

Python ищет модули в текущей папке и в путях установки. Если файл лежит рядом с программой, импорт работает. Если файл в другой папке, нужен пакет или настройка пути. Ошибка `ModuleNotFoundError` означает, что Python не нашёл файл по имени.

## Где функции ломаются

**Забытый `return`.** Функция печатает результат, а вызывающий код получает `None`. Проверка: присвойте результат переменной и напечатайте её.

**Изменяемое значение по умолчанию.** Список или словарь в параметрах сохраняется между вызовами. Исправление: `None` и создание внутри функции.

**Слишком много обязанностей.** Функция читает файл, считает, печатает и отправляет письмо. Проверять её трудно. Разделите на короткие функции с одним действием.

**Скрытая зависимость от глобальной переменной.** Результат зависит от значения, которое меняется в другом месте. Передавайте зависимость параметром.

**Имя функции совпадает с именем переменной.** После присваивания функция перестаёт быть вызываемой. Исправление: разные имена.

**Импорт по неверному пути.** `import pricing` не работает, если файл лежит в подпапке. Проверьте расположение файла и структуру пакета.

> [!PITFALL] `return` и `print` не взаимозаменяемы. Функция может напечатать ответ и вернуть `None`, и это не ошибка синтаксиса, а ошибка проектирования.

## Итоги

- Функция объявляется через `def`, принимает параметры и возвращает результат через `return`.
- `print` показывает значение, `return` передаёт его в программу.
- Локальные имена видны только внутри функции; зависимости лучше передавать параметрами.
- Изменяемые значения по умолчанию опасны, вместо них используют `None`.
- Модуль это файл с функциями; проверка `if __name__ == "__main__"` отделяет запуск от импорта.
