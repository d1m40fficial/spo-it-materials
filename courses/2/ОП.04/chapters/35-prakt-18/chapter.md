## Что требуется

Написать программу `export_report.py`, которая формирует `report.csv`. В отчёте:

1. заголовок таблицы;
2. по строке на каждый товар;
3. итоговая строка;
4. разделитель «точка с запятой»;
5. кодировка UTF-8.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает данные и создаёт пустой файл, пока в коде остались `TODO`.

### Шаг 2. Подготовьте строки

Для каждой записи вычислите стоимость `price * quantity`. Соберите строку из четырёх полей:

```text
name;price;quantity;total
```

Числа форматируйте через `:.2f` только там, где нужны копейки. Цены и количества можно писать целыми.

### Шаг 3. Запишите заголовок

Заголовок пишется первой строкой. Используйте `csv.writer`:

```python
import csv

with open("report.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, delimiter=";")
    writer.writerow(["name", "price", "quantity", "total"])
```

`newline=""` обязателен, иначе на Windows появятся пустые строки.

### Шаг 4. Запишите товары

Для каждой записи вызовите `writerow` со списком значений. Порядок значений должен совпадать с заголовком.

Ожидаемые строки:

```text
Кружка;640;3;1920.00
Блюдце;420;2;840.00
Коробка;40;10;400.00
Чайник;1250;1;1250.00
```

### Шаг 5. Добавьте итог

Последняя строка содержит слово `Итого` и общую стоимость. Пустые поля оставьте пустыми строками, но не пропускайте разделители.

```text
Итого;;;;4410.00
```

### Шаг 6. Проверьте файл

Откройте `report.csv` в VS Code и в Excel. Убедитесь, что:

- разделитель распознан;
- русские буквы читаются;
- десятичная точка, а не запятая;
- лишних пустых строк нет.

Если Excel показывает все поля в одной колонке, проверьте разделитель. Если буквы испорчены, проверьте кодировку.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустой список | только заголовок и итог 0.00 |
| одна запись | заголовок, строка, итог |
| количество 0 | стоимость 0.00 |
| название с точкой с запятой | поле взято в кавычки |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, содержимое файла, таблица проверок, вывод о кодировке. Вставьте скриншот файла в Excel или VS Code.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Файл не создаётся или содержит меньше половины строк |
| 3 | Таблица создаётся, но итог или разделитель неверны |
| 4 | Все строки и итог верны, файл открывается, отчёт заполнен |
| 5 | Все проверки и границы выполнены, кодировка объяснена |
