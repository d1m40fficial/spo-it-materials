## Что требуется

Написать программу `seats.py`, которая работает со схемой аудитории. Схема это матрица `5 x 6`, где `1` означает занятое место, `0` свободное.

Программа:

1. печатает схему;
2. считает свободные места;
3. считает занятость по рядам;
4. находит первое свободное место;
5. занимает выбранное место и проверяет результат.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает схему и нулевые счётчики. Пока в файле `TODO`, поиск не выполняется.

### Шаг 2. Напечатайте схему

Для каждой строки выведите символы: `#` для занятого места и `.` для свободного. Строки не слипаются, между рядами есть перевод строки.

Ожидаемый вид:

```text
##...#
.....#
#....#
......
##...#
```

### Шаг 3. Свободные места

Пройдите матрицу вложенными циклами и посчитайте нули. Ожидается 21 свободное место из 30.

Не используйте `len(seats) * len(seats[0]) - ...` без проверки: количество занятых мест проще посчитать тем же обходом.

### Шаг 4. Занятость по рядам

Для каждого ряда посчитайте сумму единиц. Ожидается `3, 1, 2, 0, 3`. Сумма этих чисел должна совпадать с числом занятых мест.

### Шаг 5. Первое свободное место

Обходите строки и столбцы по порядку и остановитесь на первом нуле. Ожидается `(0, 2)`. Выведите строку и столбец отдельно.

Проверьте случай, когда свободных мест нет: функция должна вернуть `None`, а не падать.

### Шаг 6. Занять место

Функция `take(seats, row, col)`:

- проверяет границы индексов;
- проверяет, что место свободно;
- ставит `1` и возвращает `True`;
- иначе возвращает `False`.

После занятия места `(0, 2)` свободных станет 20, а занятость первого ряда вырастет до 4.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| все места заняты | свободных 0, первое место `None` |
| все места свободны | свободных 30 |
| индекс вне матрицы | `False`, схема не меняется |
| занятое место | `False`, схема не меняется |
| повторное занятие | `False` |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, схема до и после, таблица проверок, вывод о порядке индексов. Вставьте скриншот.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или сделано меньше половины частей |
| 3 | Счётчики работают, но поиск или занятие места с ошибками |
| 4 | Все части решены, проверки выполнены, отчёт заполнен |
