## Что требуется

Написать программу `validate.py`, которая проверяет строки регулярными выражениями. Программа:

1. проверяет телефон;
2. проверяет дату и извлекает группы;
3. проверяет артикул;
4. находит все числа в тексте;
5. объясняет, почему строка не подошла.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает наборы строк и результаты проверки. Пока шаблоны пустые, всё считается неподходящим.

### Шаг 2. Телефон

Формат: `+7-912-345-67-89`. Шаблон:

```python
PHONE = r"^\+7-\d{3}-\d{3}-\d{2}-\d{2}$"
```

Проверяйте через `re.fullmatch`. Подходящая строка одна, остальные три должны быть отвергнуты.

### Шаг 3. Дата с группами

Формат: `18.11.2026`. Шаблон:

```python
DATE = r"^(\d{2})\.(\d{2})\.(\d{4})$"
```

Для подходящей строки выведите день, месяц и год через `group(1..3)`.

Обратите внимание: шаблон пропустит `32.11.2026`, потому что проверяет форму, а не календарь. Проверку диапазона нужно делать отдельно.

### Шаг 4. Артикул

Формат: две заглавные латинские буквы, дефис, четыре цифры.

```python
CODE = r"^[A-Z]{2}-\d{4}$"
```

Строка `ab-1234` должна быть отвергнута: строчные буквы не входят в `[A-Z]`.

### Шаг 5. Числа в тексте

Для текста `12 яблок, 7 груш и 105 слив` найдите все числа через `re.findall(r"\d+", text)`. Ожидается `['12', '7', '105']`.

`findall` возвращает строки. Для арифметики преобразуйте их в `int`.

### Шаг 6. Причины отказа

Для каждой неподходящей строки запишите, какая часть шаблона не совпала: страна, число цифр, разделитель, регистр. Это важнее, чем просто `False`.

### Шаг 7. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустая строка | отказ |
| лишние пробелы по краям | отказ |
| телефон с `8` вместо `+7` | отказ |
| дата `32.11.2026` | форма проходит, календарь нет |
| дата `1.1.2026` | отказ |
| артикул строчными | отказ |

### Шаг 8. Соберите отчёт

Заполните разделы: цель, шаблоны, таблица строк, причины отказов, вывод о границах формата. Вставьте скриншот.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или шаблоны отсутствуют |
| 3 | Шаблоны работают, но группы или причины отказов описаны неверно |
| 4 | Все части решены, проверки выполнены, отчёт заполнен |
