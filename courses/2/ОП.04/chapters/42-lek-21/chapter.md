## Размен, который кажется очевидным

В кассе нужно выдать 67 рублей монетами 50, 20, 10, 5, 2 и 1. Кассир берёт самую крупную монету, которая не больше остатка, и повторяет:

```text
67 − 50 = 17
17 − 10 = 7
7 − 5 = 2
2 − 2 = 0
```

Четыре монеты: 50, 10, 5, 2. Для этой системы монет результат оптимален, и кассир даже не проверяет другие варианты.

Такой подход называют жадным: на каждом шаге выбирается локально лучший вариант, и назад алгоритм не возвращается. Он быстрый и простой, но не всегда даёт лучший ответ.

Главная мысль занятия: **жадный алгоритм опирается на доказанное правило выбора**. Если правила нет, жадность превращается в догадку, а догадка может ошибиться.

## Как устроен жадный алгоритм

Жадный алгоритм состоит из трёх частей:

1. правило выбора: что считать лучшим на текущем шаге;
2. порядок рассмотрения: как отсортировать варианты;
3. проверка допустимости: можно ли взять вариант, не нарушив ограничения.

В размене правило это «самая крупная монета», порядок это убывание номинала, ограничение это остаток суммы.

```python
def change(amount, coins):
    coins = sorted(coins, reverse=True)
    result = []
    for coin in coins:
        while amount >= coin:
            result.append(coin)
            amount -= coin
    return result

print(change(67, [50, 20, 10, 5, 2, 1]))
```

```text
[50, 10, 5, 2]
```

Внешний цикл идёт по монетам от крупной к мелкой, внутренний берёт монету, пока она помещается. Если сумму нельзя собрать, остаток останется больше нуля, и это нужно проверить отдельно.

## Когда жадность работает

Жадный алгоритм даёт оптимум, если выполняются два свойства.

**Свойство жадного выбора.** Существует оптимальное решение, которое включает выбор, сделанный на первом шаге. Для канонической системы монет это верно, для произвольной нет.

**Оптимальная подструктура.** После сделанного выбора остаётся задача того же вида, и её оптимальное решение вместе с выбором даёт оптимум всей задачи.

Проверка обычно делается рассуждением об обмене: берём оптимальное решение, отличающееся от жадного, и показываем, что его можно заменить жадным без ухудшения. Для учебных задач достаточно понять идею, а не проводить полное доказательство.

Контрпример важнее доказательства: если найден один набор, где жадность проигрывает, свойство не выполняется.

## Жадный выбор на расписании

Классическая задача: выбрать как можно больше задач, которые не пересекаются по времени. У каждой задачи есть начало и конец.

Жадное правило: сортировать по времени окончания и брать задачу, если она начинается не раньше окончания предыдущей.

```python
def schedule(tasks):
    tasks = sorted(tasks, key=lambda task: task[1])
    selected = []
    last_end = 0
    for start, end in tasks:
        if start >= last_end:
            selected.append((start, end))
            last_end = end
    return selected
```

Сортировка по началу или по длительности не работает: короткая задача может занять весь день, а ранняя задача может закончиться поздно и заблокировать несколько других.

::figure greedy-steps | Пошаговый жадный размен: на каждом шаге берётся самая крупная подходящая монета, остаток уменьшается.

## Где жадность ошибается

**Нет доказанного правила.** «Берём самое дорогое» кажется разумным, но для рюкзака с ограничением веса это неверно. Проверка: постройте контрпример.

**Неверный ключ сортировки.** Для расписания сортируют по окончанию, а не по началу. Проверка: подставьте две задачи, где порядок меняет ответ.

**Локальный выбор блокирует будущее.** Взяв крупную монету, можно получить остаток, который нечем добить. Проверка: сумма и набор монет, где жадный остаток не собирается.

**Одинаковые значения.** При равных ключах порядок может влиять на результат. Проверка: отсортируйте устойчиво и опишите правило для равных.

**Отрицательные значения.** Жадность предполагает, что добавление варианта не ухудшает результат. С отрицательными весами это ломается.

**Смешение с динамикой.** Жадный алгоритм не хранит альтернатив. Если задача требует сравнения вариантов, нужна таблица.

> [!PITFALL] Быстрый ответ не означает правильный. Жадный алгоритм нужно либо доказать, либо проверить на полном переборе для небольших входов.

## Итоги

- Жадный алгоритм делает локально лучший выбор и не возвращается назад.
- Правило выбора, порядок и проверка допустимости задают стратегию.
- Оптимум гарантирован только при свойстве жадного выбора и оптимальной подструктуре.
- Расписание задач решается сортировкой по времени окончания.
- Контрпример важнее интуиции: один неудачный набор опровергает стратегию.
