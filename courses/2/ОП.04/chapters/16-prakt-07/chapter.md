## Что требуется

Написать программу `word_freq.py`, которая считает частоты слов в тексте и выводит:

1. общее число слов;
2. таблицу частот;
3. топ-5 слов;
4. слова, встретившиеся один раз;
5. сводку: число уникальных слов и самое частое.

Текст задан в программе. Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Подготовьте слова

Приведите текст к нижнему регистру и разбейте на слова через `split`. Для основного текста должно получиться 13 слов.

Если в тексте есть знаки препинания, уберите их у каждого слова:

```python
word = word.strip(".,!?;:")
```

Пустые строки после такой очистки пропускайте.

### Шаг 2. Заполните словарь

Для каждого слова обновите счётчик:

```python
counts[word] = counts.get(word, 0) + 1
```

`get(word, 0)` возвращает текущее число или ноль. Это короче, чем проверка `if word in counts`.

Проверьте частоты по ориентирам из `data.md`. Слово `алгоритм` должно встретиться 4 раза, `данные` 3 раза.

### Шаг 3. Отсортируйте пары

`counts.items()` даёт пары. Отсортируйте их по убыванию частоты, а при равной частоте по алфавиту:

```python
pairs = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
```

Минус перед частотой меняет порядок на убывание. Второй элемент ключа задаёт алфавитный порядок при равенстве.

Возьмите первые пять пар через срез `[:5]`. Если уникальных слов меньше пяти, срез вернёт столько, сколько есть.

### Шаг 4. Слова один раз

Соберите слова с частотой 1. Их можно найти перебором:

```python
once = [word for word, count in counts.items() if count == 1]
```

Отсортируйте результат по алфавиту, чтобы вывод был предсказуемым.

### Шаг 5. Сводка

Число уникальных слов это `len(counts)`. Самое частое слово можно взять из первой пары отсортированного списка.

Обратите внимание: если два слова имеют одинаковую максимальную частоту, «самое частое» неоднозначно. В отчёте укажите, как вы разрешаете такую ситуацию.

### Шаг 6. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| пустой текст | пустой словарь, топ пуст |
| одно слово | одна пара, топ из одного элемента |
| текст из двух слов | две пары |
| слова с заглавной буквы | считаются вместе со строчными после `lower` |
| знаки препинания | не попадают в слова |

### Шаг 7. Сравните с Counter

Модуль `collections` содержит готовый счётчик:

```python
from collections import Counter
counts = Counter(words)
```

`Counter` поддерживает `most_common(5)`. Сравните свой результат с готовым. Если числа совпали, словарь заполнен верно. Готовый класс удобен, но принцип подсчёта нужно понимать.
