## Что требуется

Написать программу `safe_input.py`, которая устойчиво работает с пользователем. Программа:

1. читает целое число и повторяет запрос при ошибке;
2. предлагает меню операций и проверяет выбор;
3. делит числа с обработкой нуля;
4. ведёт журнал ошибок;
5. печатает итоговую сводку.

Код и результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает заголовок и проходит по частям. Пока в файле остались `TODO`, проверки не выполняются.

### Шаг 2. Безопасное целое число

Напишите функцию `read_int(prompt, attempts=3)`:

1. выводит приглашение;
2. читает строку;
3. пытается преобразовать в `int`;
4. при `ValueError` сообщает об ошибке и повторяет;
5. после исчерпания попыток возвращает `None`.

Подсказка: цикл `while` с счётчиком и `try/except ValueError`. Не перехватывайте все исключения подряд: нужен именно `ValueError`.

Проверьте на вводе `abc`, `12.5`, `7`. Первые два должны дать сообщение, третье вернуть `7`.

### Шаг 3. Меню операций

Программа предлагает:

```text
1. Сложить
2. Вычесть
3. Разделить
0. Выход
```

Функция `read_choice()` принимает только `1`, `2`, `3` или `0`. Неверный пункт повторяет вопрос. Для проверки используйте `in` по строке или преобразование в число с обработкой ошибки.

### Шаг 4. Деление

Функция `safe_divide(a, b)` возвращает результат или `None`.

```python
try:
    return a / b
except ZeroDivisionError:
    return None
```

При `b == 0` программа выводит понятное сообщение и записывает его в журнал. Не позволяйте ошибке завершить программу.

### Шаг 5. Журнал ошибок

Заведите список `errors`. Каждая запись содержит место и причину:

```text
read_int: введено "abc"
read_choice: пункт 5
safe_divide: делитель 0
```

В конце программа печатает число ошибок и сами записи. Если ошибок не было, выводится сообщение об успешной работе.

### Шаг 6. Сводка

Соберите итог:

- сколько раз запрашивали число;
- сколько попыток оказались неудачными;
- сколько операций выполнено;
- сколько ошибок записано.

Сводка печатается даже при ошибках. Именно ради неё программа не завершается на первом сбое.

### Шаг 7. Проверьте сценарии

| Сценарий | Ожидание |
|---|---|
| корректный ввод с первого раза | ошибок нет |
| два неверных числа, затем верное | две записи в журнале |
| деление на ноль | сообщение, запись в журнале |
| неверный пункт меню | повтор запроса |
| три неверных числа подряд | возврат `None`, запись |
| выход через `0` | сводка без лишних запросов |

### Шаг 8. Соберите отчёт

Заполните разделы:

1. Тема и цель.
2. Код.
3. Результаты пяти частей.
4. Таблица сценариев.
5. Вывод: почему конкретное исключение лучше общего.

Вставьте скриншот запуска с ошибочным вводом.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Программа не запускается или выполнено меньше половины частей |
| 3 | Основные части решены, но ошибки ввода завершают программу |
| 4 | Все части решены, сценарии проверены, отчёт заполнен, есть мелкие недочёты |
| 5 | Все части решены, границы проверены, обработка исключений объяснена |

> [!PITFALL] `except:` без типа перехватывает и опечатки, и прерывание с клавиатуры. Указывайте `ValueError` или `ZeroDivisionError` явно.
