## Что требуется

Дана сетка стоимости прохода. Нужно пройти из левого верхнего угла в правый нижний, двигаясь только вправо и вниз, и заплатить как можно меньше.

Программа `min_path.py`:

1. хранит сетку;
2. строит таблицу минимальных стоимостей;
3. находит минимальную стоимость;
4. восстанавливает маршрут;
5. сравнивает результат с жадным проходом.

Результаты переносятся в `report_template.docx`.

## Ход работы

### Шаг 1. Запустите заготовку

```bash
python starter.py
```

Заготовка печатает сетку и нулевую стоимость. Пока в файле `TODO`, таблица не заполняется.

### Шаг 2. Создайте таблицу

Размер таблицы совпадает с сеткой. `dp[r][c]` это минимальная стоимость пути до клетки `(r, c)`.

```python
rows = len(grid)
cols = len(grid[0])
dp = [[0] * cols for _ in range(rows)]
```

Строки создаются отдельно, иначе все они будут ссылаться на один список.

### Шаг 3. Заполните таблицу

База: `dp[0][0] = grid[0][0]`.

Первая строка и первый столбец заполняются без выбора: путь в них единственный.

```python
for c in range(1, cols):
    dp[0][c] = dp[0][c - 1] + grid[0][c]
for r in range(1, rows):
    dp[r][0] = dp[r - 1][0] + grid[r][0]
```

Остальные клетки:

```python
dp[r][c] = grid[r][c] + min(dp[r - 1][c], dp[r][c - 1])
```

Ожидаемая минимальная стоимость для сетки из задания равна 8.

### Шаг 4. Восстановите маршрут

Идите от правого нижнего угла к началу. На каждом шаге сравнивайте `dp[r - 1][c]` и `dp[r][c - 1]` и переходите в меньшую клетку. В начале пути разверните список.

Ожидаемый маршрут: вправо, вправо, вниз, вниз, вправо.

### Шаг 5. Сравните с жадным проходом

Жадный проход выбирает соседнюю клетку с меньшей стоимостью, не заглядывая вперёд. Реализуйте его отдельной функцией.

Для сетки из задания жадный проход даёт 10, а оптимальный 8. Объясните в отчёте, почему жадный выбор проиграл.

### Шаг 6. Проверьте границы

| Что проверить | Ожидание |
|---|---|
| сетка 1 x 1 | стоимость равна клетке |
| одна строка | путь только вправо |
| один столбец | путь только вниз |
| сетка 2 x 2 | минимум из двух путей |
| пустая сетка | сообщение об ошибке |

### Шаг 7. Оформите вывод

Напечатайте сетку, таблицу `dp` и маршрут в виде стрелок или координат. Для чисел используйте выравнивание по ширине.

### Шаг 8. Соберите отчёт

Заполните разделы: цель, код, таблица, маршрут, сравнение с жадным, вывод. Вставьте скриншот.
