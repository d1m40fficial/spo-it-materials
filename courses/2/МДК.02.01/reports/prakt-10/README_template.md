# Учебный продукт: заявки колледжа

## Назначение

Кратко: какую задачу решает продукт и для кого.

## Требования

- Python 3.11 или новее;
- SQLite;
- браузер.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откройте адрес, который вывел сервер.

## Проверка

```bash
python -m pytest -q
```

## Структура

```text
app.py
tests/
docs/
```

## Ограничения

- одновременная запись в SQLite ограничена;
- уведомления по почте не отправляются;
- мобильного приложения нет.
