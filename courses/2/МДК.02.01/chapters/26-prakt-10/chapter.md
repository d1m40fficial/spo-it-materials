## Что требуется

Собрать комплект документации для учебного продукта:

1. README;
2. описание API;
3. руководство пользователя.

Инструкции проверяются на чистом окружении. Результаты переносятся в `report_template.docx`.

## Что понадобится

|---|---|---|
| `README_template.md` | `.../prakt-10/README_template.md` | заготовка README |
| Код продукта | рабочая папка | описание API и запуска |

## Ход работы

### Шаг 1. Определите читателей

Для каждого документа назовите читателя и вопрос, на который он отвечает.

Не смешивайте руководство пользователя и README разработчика.

### Шаг 2. Заполните README

Возьмите `README_template.md` и заполните разделы под свой продукт. Команды должны быть точными.

Проверьте, что файл `requirements.txt` существует и содержит нужные зависимости.

### Шаг 3. Опишите API

Выпишите конечные точки: метод, адрес, параметры, успешный ответ, ошибки. Добавьте пример запроса и ответа.

Ошибки описывайте кодами и понятным текстом, а не «что-то пошло не так».

### Шаг 4. Составьте руководство

Опишите три сценария пользователя: создать заявку, найти свои заявки, закрыть заявку.

Для каждого укажите шаги, ожидаемый результат и действие при ошибке.

### Шаг 5. Проверьте на чистом окружении

Скопируйте проект в чистую папку или создайте новое виртуальное окружение. Выполните инструкцию README от начала до конца.

Запишите, что пришлось исправить.

### Шаг 6. Соберите отчёт

Заполните таблицы, вставьте фрагменты документов и ответьте на вопросы.

## Критерии оценки

| Балл | Что оценивается |
|---:|---|
| 1 | Работа сделана с ИИ или скопирована без возможности объяснить и исправить |
| 2 | Документы отсутствуют или команды не работают |
| 3 | Документы есть, но примеры или ошибки API неполные |
| 4 | Все части выполнены, отчёт заполнен, есть мелкие недочёты |
| 5 | Инструкции проверены с нуля, API и сценарии описаны точно |

## Что сдаётся

- `README.md`, описание API и руководство пользователя.
- `report.docx` с проверкой установки и ответами.

> [!PITFALL] Команда, которую не запускали с чистого листа, почти всегда содержит пропущенный шаг. Проверка установки обязательна.
