# Учебный комплект ОП.01

Комплект к дисциплине «Операционные системы и среды». Внутри примеры журналов
и шаблоны отчётов. Готовых ответов и разобранных инцидентов нет.

## Состав

- `data/auth.log`: входы, sudo и неудачные попытки.
- `data/syslog`: события загрузки, служб и дисковой ошибки.
- `data/windows-events.txt`: события Windows для разбора.
- `templates/`: шаблоны отчётов по всем практикам.

## Ограничения

Все события учебные. Стенд собирается в VirtualBox, настройки хоста не меняются.
