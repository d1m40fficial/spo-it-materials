Импорт · форма данных

CSV: что ломается

external_id;name;inn
C-1001;"ООО ""Стройбаза""";0071234567
C-1002;ИП Ковалёв;504700987654
  • Разделитель: здесь точка с запятой, а не запятая.
  • BOM: невидимая метка перед заголовком.
  • 007... Excel превратит в число и потеряет ноль.
  • Кавычки: внутри поля кавычка удваивается.

JSON: что проверять

{
  "external_id": "C-1001",
  "inn": "0071234567",
  "address": { "city": "Тверь" },
  "credit_limit": null
}
  • Дубль ключа: парсеры выберут разные значения.
  • null не равен отсутствию ключа.
  • Число строкой: "250000.00" требует преобразования.
  • Вложенность: адрес нужно развернуть в поля.

Один объект, две формы. CSV удобен для таблицы, JSON для связей. Импорт должен знать, где заканчивается форма файла и начинается правило приёмника.
