# Практика 1. IP-адресация и маски

## Исходные данные

Сеть: `192.168.10.0/24`.

| Отдел | Нужно узлов |
|---|---:|
| продажи | 50 |
| гости | 30 |
| склад | 20 |
| серверная | 10 |

## Формулы

- число адресов в подсети: `2^h`, где `h` это биты узла;
- число узлов: `2^h - 2`;
- шаг блока равен числу адресов.

## Команды проверки

Linux:

```bash
ip addr
ping -c 3 <адрес>
```

Windows:

```text
ipconfig
ping <адрес>
```
