# Практика 2. Проверка веб-службы

## Адреса для проверки

| Адрес | Что проверяется |
|---|---|
| `https://example.com/` | обычный ответ 200 |
| `https://httpbin.org/status/404` | ресурс не найден |
| `https://httpbin.org/redirect/1` | перенаправление 302 |
| `https://httpbin.org/delay/2` | задержка около 2 секунд |
| `http://example.com/` | сравнение с HTTPS |

Если внешний адрес недоступен, используйте любой рабочий сайт и его несуществующую страницу.
