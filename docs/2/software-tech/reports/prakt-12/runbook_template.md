# Инструкция по передаче системы

## 1. Что передаётся

- версия продукта;
- база данных;
- файлы конфигурации без секретов;
- документация;
- контакты поддержки.

## 2. Порядок внедрения

1. Сделать резервную копию.
2. Проверить миграцию на копии.
3. Остановить старую версию.
4. Применить миграцию.
5. Запустить новую версию.
6. Выполнить дымовые проверки.
7. Сообщить пользователям.

## 3. Откат

Опишите: когда запускается, кто принимает решение, какие команды выполняются, сколько занимает.

## 4. Проверки после запуска

- страница открывается;
- вход работает;
- заявка создаётся;
- заявка закрывается;
- отчёт строится;
- журналы пишутся.

## 5. Поддержка

Заполните: канал обращений, время реакции, время решения, ответственный, порядок обновления.
