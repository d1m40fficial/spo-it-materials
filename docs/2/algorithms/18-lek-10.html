01Журнал, который растёт каждый день

Сервер пишет журнал событий. Каждая строка содержит дату, уровень и сообщение:

2026-11-18 09:12:01;INFO;Запуск
2026-11-18 09:12:05;INFO;Чтение файла
2026-11-18 09:12:07;WARNING;Пустая строка
2026-11-18 09:12:09;ERROR;Файл не найден

Нужно посчитать, сколько было ошибок и предупреждений, и сохранить сводку в отдельный файл. Вручную это делается копированием строк в таблицу. Скрипт делает то же самое за секунду и не устаёт.

Для этого нужны три операции: открыть файл, прочитать его построчно и записать итог. Каждая из них имеет свои правила. Если открыть файл не в той кодировке, русский текст превратится в набор символов. Если забыть закрыть файл, изменения могут не сохраниться. Если указать неверный путь, программа завершится ошибкой ещё до первой строки.

Главная мысль занятия: файл это внешний ресурс, который открывают на время, читают или пишут и обязательно закрывают. Контекстный менеджер with делает закрытие автоматическим.

02Открытие файла

Файл открывают функцией open. У неё три важных аргумента: путь, режим и кодировка.

f = open("log.txt", "r", encoding="utf-8")

Режим "r" означает чтение. Другие режимы:

Режим Что делает
"r" читает существующий файл
"w" создаёт файл или очищает существующий
"a" дописывает в конец
"x" создаёт файл, но падает, если он уже есть
"rb" читает двоичные данные

Кодировка utf-8 поддерживает русские буквы. Если её не указать, Python возьмёт кодировку системы, и на другом компьютере результат может отличаться. Для учебных текстовых файлов кодировку указывают всегда.

После работы файл закрывают:

f.close()

Если этого не сделать, операционная система может не записать буфер на диск сразу. Для чтения это обычно незаметно, для записи может привести к потере данных.

03Контекстный менеджер

Конструкция with закрывает файл автоматически, даже если внутри произошла ошибка.

with open("log.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

Файл закрывается при выходе из блока. Отдельный close() не нужен. Это предпочтительный способ работы с файлами.

04Чтение

Способы чтения отличаются объёмом.

with open("log.txt", encoding="utf-8") as f:
    text = f.read()

read() читает весь файл в одну строку. Для маленького файла это удобно, для большого расходует память.

with open("log.txt", encoding="utf-8") as f:
    first = f.readline()
    second = f.readline()

readline() читает одну строку. readlines() возвращает список строк. Но самый экономный способ это перебор файла в цикле: каждая итерация читает одну строку.

with open("log.txt", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if not line:
            continue
        parts = line.split(";")
        print(parts)

strip() убирает перевод строки \n в конце. Без него последнее поле будет содержать невидимый символ, и сравнение parts[-1] == "Запуск" не сработает.

Пустые строки пропускают через continue. В журналах они встречаются между блоками и ломают разбор.

05Запись результата

Для записи используют режим "w" или "a".

with open("report.txt", "w", encoding="utf-8") as out:
    out.write("Сводка\n")
    out.write("ERROR: 1\n")

"w" очищает файл перед записью. Если файл уже был, его содержимое исчезнет. "a" дописывает в конец и сохраняет прежние строки.

Метод write не добавляет перевод строки сам. Его указывают явно:

out.write("ERROR: 1\n")

Для нескольких строк удобно собрать список и записать его через writelines, добавив переводы заранее:

lines = ["Сводка\n", "ERROR: 1\n", "WARNING: 1\n"]
out.writelines(lines)

print тоже умеет писать в файл:

with open("report.txt", "w", encoding="utf-8") as out:
    print("Сводка", file=out)

print добавляет перевод строки автоматически, поэтому для отчётов этот вариант короче.

06Разбор строки

Журнал с разделителем ; разбирают через split:

line = "2026-11-18 09:12:09;ERROR;Файл не найден"
parts = line.split(";")
time = parts[0]
level = parts[1]
message = parts[2]

Если сообщение само содержит точку с запятой, parts[2] окажется только началом. Надёжнее ограничить число делений:

parts = line.split(";", 2)

Третий аргумент говорит, сколько раз делить. Остаток строки попадёт в последний элемент.

Для табличных данных с запятыми есть модуль csv. Он сам обрабатывает кавычки и разделители внутри полей. В простых учебных журналах достаточно split, но для настоящих выгрузок лучше csv.

07Ошибки пути и кодировки

Файл не найден. FileNotFoundError означает, что путь неверен или файл лежит в другой папке. Программа ищет файл относительно текущей рабочей папки, а не относительно файла с кодом. Проверка: напечатайте os.getcwd() и список файлов в папке.

Не та кодировка. UnicodeDecodeError возникает, когда файл записан в одной кодировке, а прочитан в другой. Исправление: указать encoding="utf-8" или ту кодировку, в которой файл сохранён.

Забытый strip. В конце строки остаётся \n, и сравнение не срабатывает. Исправление: line.strip() сразу после чтения.

Очистка файла режимом "w". Повторный запуск программы затирает прошлый отчёт. Если нужна история, используйте "a" или имя с датой.

Чтение после конца файла. После read() указатель стоит в конце. Повторный read() вернёт пустую строку. Читайте файл один раз или возвращайтесь через seek(0).

Абсолютный путь в коде. Путь с буквой диска не работает на другом компьютере. Используйте относительный путь или pathlib.

`open("log.txt")` ищет файл в текущей папке терминала, а не рядом с файлом программы. Запуск из другой папки ломает путь, хотя код не менялся.

08Итоги

  • Файл открывают через open с путём, режимом и кодировкой.
  • with закрывает файл автоматически, даже при ошибке.
  • Читать большой файл лучше построчно в цикле.
  • "w" очищает файл, "a" дописывает; write не добавляет перевод строки.
  • strip убирает \n, split разбирает поля, encoding задаёт кодировку.
