# Данные практики 9

## Файл журнала

Файл `log.csv` лежит рядом со `starter.py`. Разделитель полей это точка с запятой.

```text
2026-11-18 09:12:01;INFO;Запуск
2026-11-18 09:12:05;INFO;Чтение файла
2026-11-18 09:12:07;WARNING;Пустая строка
2026-11-18 09:12:09;ERROR;Файл не найден
2026-11-18 09:12:11;INFO;Повторная попытка
2026-11-18 09:12:14;ERROR;Доступ запрещён
2026-11-18 09:12:18;INFO;Завершение
```

## Ориентиры для проверки

| Показатель | Значение |
|---|---:|
| непустых строк | 7 |
| INFO | 4 |
| WARNING | 1 |
| ERROR | 2 |
| сообщений об ошибках | 2 |

## Проверки

| Что проверить | Ожидание |
|---|---|
| пустая строка | пропускается, счётчик не растёт |
| лишние пробелы | `strip` убирает их до разбора |
| сообщение с `;` | остаётся в последнем поле благодаря `split(";", 2)` |
| отсутствующий файл | программа сообщает об ошибке, а не падает |
| повторный запуск | `report.txt` перезаписывается |
