## Ожидаемое поведение

| Вход | Ожидание |
|---|---|
| `[10, 20, 30]` | 20 |
| `[]` | 0.0 |
| `[7]` | 7 |

### is_even(n)

| Вход | Ожидание |
|---:|---|
| 4 | True |
| 7 | False |
| 0 | True |

### clamp(value, low, high)

| Вход | Ожидание |
|---|---|
| `50, 0, 100` | 50 |
| `150, 0, 100` | 100 |
| `-10, 0, 100` | 0 |

| Вход | Ожидание |

| `[1, 2, 3], 2` | 1 |

## Подсказки по отчёту

- `FAIL` означает неверное значение.
- `ERROR` означает исключение во время теста.
- Причина формулируется одной фразой без пересказа кода.
