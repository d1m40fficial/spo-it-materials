# Данные практики 5

## Текст для разбора

```text
  Алгоритм   это конечная последовательность точных шагов. Алгоритм превращает входные данные в результат. Хороший алгоритм понятен исполнителю.  
```

## Артикулы для проверки

| Артикул | Что проверяется |
|---|---|
| `AB-1234` | правильный формат |
| `ab-1234` | строчные буквы |
| `AB-123` | не хватает цифры |
| `A1-1234` | цифра вместо второй буквы |
| `CD-0007` | правильный формат с нулями |

## Ожидаемые ориентиры

- после нормализации в тексте 16 слов;
- самое длинное слово содержит 16 символов;
- слово «алгоритм» встречается 3 раза;
- слов длиннее шести символов несколько, их точный список зависит от того, как считать знаки препинания.

## Проверки

| Что проверить | Как проверить |
|---|---|
| лишние пробелы | в начале и в конце строки их быть не должно |
| регистр | весь текст в нижнем регистре |
| двойные пробелы | между словами ровно один пробел |
| пустой текст | программа не должна падать |
| артикул без дефиса | должен считаться неверным |
