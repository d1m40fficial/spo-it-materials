# Данные практики 19

## Схема мест

```text
##...#
.....#
#....#
......
##...#
```

`#` занято, `.` свободно.

## Ориентиры

| Показатель | Значение |
|---|---:|
| всего мест | 30 |
| занято | 9 |
| свободно | 21 |
| занято по рядам | 3, 1, 2, 0, 3 |
| первое свободное | (0, 2) |
| после занятия (0, 2) | свободно 20 |

## Проверки

| Что проверить | Ожидание |
|---|---|
| все места заняты | свободно 0, первое `None` |
| все места свободны | свободно 30 |
| индекс 10, 10 | `False`, схема не меняется |
| занятое место | `False` |
| повторное занятие | `False` |
| сумма по рядам | равна числу занятых |
